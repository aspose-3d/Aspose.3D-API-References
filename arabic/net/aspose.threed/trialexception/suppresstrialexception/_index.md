## TrialException.SuppressTrialException property

يعيّن هذا إلى true لكتم استثناء التجربة للاستخدام غير المرخص، لكن القيود لن تُرفع. لرفع القيود، يرجى استخدام ترخيص صحيح. وتعيين هذا إلى true يعني أيضًا أنك على علم بالقيود غير المرخصة.

```csharp
public static bool SuppressTrialException { get; set; }
```
