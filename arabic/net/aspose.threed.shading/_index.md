جميع الفئات المتعلقة بالتظليل معرفة في هذه المساحة.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [LambertMaterial](./lambertmaterial/) | مادة لنموذج تظليل لامبرت |
| [Material](./material/) | المادة تُعرّف المعلمات اللازمة للمظهر البصري للهندسة. توفر Aspose.3D نموذج تظليل لـ [`LambertMaterial`](../aspose.threed.shading/lambertmaterial/)، [`PhongMaterial`](../aspose.threed.shading/phongmaterial/) و [`ShaderMaterial`](../aspose.threed.shading/shadermaterial/). |
| [PbrMaterial](./pbrmaterial/) | مادة للتصيير القائم على الفيزياء استنادًا إلى لون الألبيدو/المعدن/الخشونة |
| [PbrSpecularMaterial](./pbrspecularmaterial/) | مادة للتصيير القائم على الفيزياء استنادًا إلى اللون المنتشر/اللمعان/السطوع |
| [PhongMaterial](./phongmaterial/) | مادة لنموذج تظليل بلين-فونغ. |
| [ShaderMaterial](./shadermaterial/) | تسمح مادة الـ shader بوصف المادة بواسطة محرك تصيير خارجي أو لغة shader. يستخدم [`ShaderMaterial`](../aspose.threed.shading/shadermaterial/) [`ShaderTechnique`](../aspose.threed.shading/shadertechnique/) لوصف تفاصيل التصيير المحددة، وسيتم اختيار الأنسب وفقًا لمنصة التصيير النهائية. على سبيل المثال، يمكن لكائن [`ShaderMaterial`](../aspose.threed.shading/shadermaterial/) أن يحتوي على تقنيتين، إحداهما معرفة بـ HLSL، والأخرى معرفة بـ GLSL. تحت منصة غير نافذة يجب استخدام GLSL بدلاً من HLSL |
| [ShaderTechnique](./shadertechnique/) | تقنية shader تمثل تنفيذًا محددًا للتصيير. |
| [Texture](./texture/) | هذه الفئة تعرف الملمس من ملف خارجي. |
| [TextureBase](./texturebase/) | الفئة الأساسية لجميع الملمسات المحددة. الملمس يحدد الشكل والمظهر لسطح الهندسة. |
| [TextureSlot](./textureslot/) | فتحة الملمس في [`Material`](../aspose.threed.shading/material/)، يمكن تعدادها عبر مثيل المادة. |
## تعداد

| تعداد | الوصف |
| --- | --- |
| [AlphaSource](./alphasource/) | يحدد ما إذا كان الملمس يحتوي على قناة ألفا. |
| [TextureFilter](./texturefilter/) | خيارات الفلترة أثناء أخذ عينات الملمس. |
| [WrapMode](./wrapmode/) | وضع تغليف الملمس. |
