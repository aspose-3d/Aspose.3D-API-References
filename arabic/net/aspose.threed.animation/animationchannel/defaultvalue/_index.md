## AnimationChannel.DefaultValue property

يحصل أو يعيّن القيمة الافتراضية للقناة. إذا لم يكن للقناة أي تسلسلات إطارات رئيسية متصلة، ستُستخدم القيمة الافتراضية أثناء تقييم الرسوم المتحركة. سيناريو واقعي: الرسوم المتحركة تحرك فقط إحداثي x للعقدة، ولا يتغير y و z، ثم تُستخدم القيمة الافتراضية أثناء تقييم الترجمة الكاملة.

```csharp
public object DefaultValue { get; set; }
```
