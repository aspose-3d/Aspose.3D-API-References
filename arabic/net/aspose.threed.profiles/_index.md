جميع فئات الملف الشخصي ثنائية الأبعاد معرفة في هذه المساحة.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [ArbitraryProfile](./arbitraryprofile/) | هذه الفئة تسمح لك بإنشاء ملف شخصي ثنائي الأبعاد مباشرةً من منحنى عشوائي. |
| [CenterLineProfile](./centerlineprofile/) | ملف تعريف خط المركز المتوافق مع IFC |
| [CircleShape](./circleshape/) | ملف تعريف دائرة متوافق مع IFC، يمكن استخدامه لإنشاء شبكة عبر [`LinearExtrusion`](../aspose.threed.entities/linearextrusion/) |
| [CShape](./cshape/) | ملف تعريف شكل C متوافق مع IFC يُعرّف بالمعلمات. الموضع المركزي للملف التعريفي هو في مركز صندوق الحدود. |
| [EllipseShape](./ellipseshape/) | شكل إهليلجي متوافق مع IFC يُعرّف بالمعلمات. الموضع المركزي للملف التعريفي هو في مركز صندوق الحدود. |
| [FontFile](./fontfile/) | ملف الخط يحتوي على تعريفات للرموز، يُستخدم لإنشاء ملف تعريف نصي. |
| [HollowCircleShape](./hollowcircleshape/) | ملف تعريف دائرة مجوفة متوافق مع IFC. |
| [HollowRectangleShape](./hollowrectangleshape/) | شكل مستطيل مجوف متوافق مع IFC مع زوايا داخلية/خارجية مستديرة. |
| [HShape](./hshape/) | يقدم [`HShape`](../aspose.threed.profiles/hshape/) المعلمات التعريفية لشكل 'H' أو 'I'. |
| [LShape](./lshape/) | ملف تعريف شكل L متوافق مع IFC يُعرّف بالمعلمات. |
| [MirroredProfile](./mirroredprofile/) | ملف تعريف مرآة متوافق مع IFC. يعرّف هذا الملف تعريفًا جديدًا عن طريق عكس الملف الأساسي حول محور y. |
| [ParameterizedProfile](./parameterizedprofile/) | الفئة الأساسية لجميع الملفات التعريفية المعيّرة. |
| [Profile](./profile/) | ملف تعريف ثنائي الأبعاد في مستوى xy |
| [RectangleShape](./rectangleshape/) | شكل مستطيل متوافق مع IFC مع زوايا مدورة. |
| [Text](./text/) | ملف تعريف نصي، يصف هذا الملف التعريفي الخطوط باستخدام الخط والنص. |
| [TrapeziumShape](./trapeziumshape/) | شكل شبه منحرف متوافق مع IFC معرف بالمعلمات. |
| [TShape](./tshape/) | شكل T متوافق مع IFC معرف بالمعلمات. |
| [UShape](./ushape/) | شكل U متوافق مع IFC معرف بالمعلمات. |
| [ZShape](./zshape/) | ملف تعريف شكل Z متوافق مع IFC معرف بالمعلمات. |
