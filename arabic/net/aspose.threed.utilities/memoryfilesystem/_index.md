### أمثلة

الكود التالي يوضح كيفية تصدير الملف إلى الذاكرة، ويتضمن الملف التابع باستخدام MemoryFileSystem.

```csharp
//إنشاء مشهد بمواد
Scene scene = new Scene();
scene.RootNode.CreateChildNode(new Box()).Material = new LambertMaterial();
//إنشاء خيار حفظ وتحديد نظام الملفات، بحيث يُكتب الملف التابع إلى الذاكرة.
var opt = FileFormat.WavefrontOBJ.CreateSaveOptions();
var mfs = new MemoryFileSystem();
opt.FileSystem = mfs;
//اسم ملف مادة الـ obj مرتبط باسم ملف الـ obj، لذا نحتاج إلى اسم صريح.
opt.FileName = "test.obj";
using (var ms = new MemoryStream())
{
    scene.Save(ms, opt);
}
//تم كتابة test.obj إلى المتغيّر ms، ويمكننا أيضًا الحصول على محتوى ملف test.mtl بواسطة
var materialFile = mfs.GetFileContent("test.mtl");
```
