## GltfSaveOptions.UseCommonMaterials property

تسلسل المواد باستخدام امتدادات المواد المشتركة KHR، القيمة الافتراضية هي false. ضبطها على false سيتسبب في أن تقوم Aspose.3D بتصدير مجموعة من تظليل القمم/الشرائح إذا كان ExportShaders مفعلاً.

```csharp
public bool UseCommonMaterials { get; set; }
```
