## Discreet3dsSaveOptions.HighPreciseColor property

إذا كان هذا true، سيستخدم ملف 3ds المُولد لونًا عالي الدقة، يعني أن كل قناة من الأحمر/الأخضر/الأزرق تكون بتمثيل 32 بت عائم. وإلا سيستخدم الملف المُولد لونًا 24 بت، حيث كل قناة تستخدم 8 بت بايت. القيمة الافتراضية هي false، لأن ليس كل التطبيقات تدعم اللون عالي الدقة.

```csharp
public bool HighPreciseColor { get; set; }
```
