## Discreet3dsSaveOptions.DuplicatedNameSeparator property

الفاصل بين اسم الكائن والعداد المتكرر، القيمة الافتراضية هي "_". عندما يحتوي المشهد على كائنات تستخدم نفس الاسم، سيقوم مُصدّر 3DS الخاص بـ Aspose.3D بإنشاء اسم مختلف للكائن. على سبيل المثال هناك عقدتين باسم "Box"، العقدة الأولى ستحمل الاسم "Box"، والعقدة الثانية ستحصل على اسم جديد "Box_2" باستخدام الإعداد الافتراضي.

```csharp
public string DuplicatedNameSeparator { get; set; }
```
