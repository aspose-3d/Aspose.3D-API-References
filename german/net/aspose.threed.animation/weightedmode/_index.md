## WeightedMode enumeration

Gewichteter Modus.

```csharp
[Flags]
public enum WeightedMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Sowohl Out- als auch Next-In-Gewichte werden nicht verwendet. Wenn die Berechnung Tangenteninformationen benötigt, wird der Standardwert(0.3333) verwendet. |
| OutWeight | `1` | Out(rechts) Tangente ist gewichtet. |
| NextInWeight | `2` | Next-in(links) Tangente ist gewichtet. |
| Both | `3` | Sowohl Out- als auch Next-In-Tangenten sind gewichtet. |
