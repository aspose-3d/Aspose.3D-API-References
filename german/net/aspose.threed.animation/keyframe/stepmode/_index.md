## KeyFrame.StepMode property

Liest oder setzt den Schrittmodus des Schlüssels. Wenn der Interpolationstyp Konstant ist, entscheidet list.data[index], welcher Schlüsselbildwert während der Interpolation verwendet wird. Ein PreviousValue bedeutet, dass der Wert des linken Schlüsselbildes verwendet wird. Ein NextValue bedeutet, dass der Wert des nächsten rechten Schlüsselbildes verwendet wird.

```csharp
public StepMode StepMode { get; set; }
```

### Property Value

Der Schrittmodus.
