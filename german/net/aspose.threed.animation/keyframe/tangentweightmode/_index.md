## KeyFrame.TangentWeightMode property

Ruft den Tangenten-Gewichtsmodus des Schlüssels ab oder legt ihn fest. Der Ausgangstangente oder die nächste Eingangs‑Tangente kann durch Auswahl des richtigen [`WeightedMode`](../../weightedmode/) angepasst werden.

```csharp
public WeightedMode TangentWeightMode { get; set; }
```

### Property Value

Der Tangenten-Gewichtsmodus.
