## Interpolation enumeration

Der Interpolationstyp des Keyframes.

```csharp
public enum Interpolation
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Constant | `0` | Der Wert bleibt konstant auf dem Wert des ersten Punktes bis zum nächsten Segment. |
| Linear | `1` | Lineare Interpolation ist eine gerade Linie zwischen zwei Punkten. |
| Bezier | `2` | Ein Bezier- oder Hermite-Spline. |
| BSpline | `3` | Basis-Splines werden durch eine Reihe von Kontrollpunkten definiert, wobei die Kurve garantiert nur durch den ersten und den letzten Punkt verläuft. |
| CardinalSpline | `4` | Ein Cardinal-Spline ist ein kubischer Hermite-Spline, dessen Tangenten durch die Endpunkte und einen Spannungsparameter definiert werden. |
| TCBSpline | `5` | Auch Kochanek-Bartels-Spline genannt, wird das Tangentenverhalten durch Spannung/Bias/Kontinuität definiert |
