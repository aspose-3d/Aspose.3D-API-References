## ReferenceMode enumeration

`ReferenceMode` definiert, wie Mapping-Informationen gespeichert und referenziert werden von.

```csharp
public enum ReferenceMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Direct | `0` | Daten werden direkt referenziert |
| Index | `1` | Daten werden über Index referenziert |
| IndexToDirect | `2` | Daten werden über den Index referenziert und dann über den Index in der Datenliste von [`VertexElement`](../vertexelement/) abgerufen. |
