## Frustum.RotationMode property

Gibt den Orientierungsmodus des Frustums zurück oder legt ihn fest. Diese Eigenschaft funktioniert nur, wenn das [`Target`](../target/) null ist. Wenn der Wert FixedTarget ist, wird die Richtung immer über die Eigenschaft [`LookAt`](../lookat/) berechnet. Andernfalls wird [`LookAt`](../lookat/) immer über die [`Direction`](../direction/) berechnet.

```csharp
public RotationMode RotationMode { get; set; }
```
