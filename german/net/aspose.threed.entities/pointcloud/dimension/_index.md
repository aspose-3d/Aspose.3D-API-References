## PointCloud.Dimension property

Wenn ein Dimensionswert für die Punktwolke vorhanden ist, weist dies auf eine organisierte Punktwolke hin. Ohne angegebene Größe wird sie als unorganisierte Punktwolke betrachtet. Eine organisierte Punktwolke bedeutet, dass sie eine bildähnliche Struktur hat.
