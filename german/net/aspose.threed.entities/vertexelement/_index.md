## VertexElement class

Basisklasse für Vertex‑Elemente. Ein Vertex‑Elementtyp wird durch VertexElementType identifiziert. Ein VertexElement beschreibt, wie das Vertex‑Element auf eine Geometrieoberfläche abgebildet wird und wie die Abbildungsinformationen im Speicher angeordnet sind. Ein VertexElement enthält Normalen, UVs oder andere Arten von Informationen.
