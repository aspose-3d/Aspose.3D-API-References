## NurbsCurve.Rational property

Gibt an oder legt fest, ob sie rational ist; dieser Wert gibt an, ob dieses [`NurbsCurve`](../) ein rationaler Spline oder ein nicht-rationaler Spline ist. Nicht-rationaler B-Spline ist ein Spezialfall von rationalen B-Splines.

```csharp
public bool Rational { get; set; }
```

### Property Value

Wahr, wenn es ein rationaler Spline ist; andernfalls ist falsch, wenn es ein nicht-rationaler Spline ist.
