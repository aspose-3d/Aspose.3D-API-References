Alle 2D‑Profilklassen sind in diesem Namensraum definiert.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ArbitraryProfile](./arbitraryprofile/) | Diese Klasse ermöglicht es Ihnen, ein 2D-Profil direkt aus einer beliebigen Kurve zu erstellen. |
| [CenterLineProfile](./centerlineprofile/) | IFC-kompatibles Mittellinienprofil |
| [CircleShape](./circleshape/) | IFC-kompatibles Kreisprofil, das verwendet werden kann, um ein Mesh mittels [`LinearExtrusion`](../aspose.threed.entities/linearextrusion/) zu erzeugen. |
| [CShape](./cshape/) | IFC kompatibles C-förmiges Profil, das durch Parameter definiert ist. Die zentrale Position des Profils befindet sich in der Mitte der Begrenzungsbox. |
| [EllipseShape](./ellipseshape/) | IFC kompatible Ellipsenform, die durch Parameter definiert ist. Die zentrale Position des Profils befindet sich in der Mitte der Begrenzungsbox. |
| [FontFile](./fontfile/) | Fontdatei enthält Definitionen für Glyphen, die zum Erstellen von Textprofilen verwendet werden. |
| [HollowCircleShape](./hollowcircleshape/) | IFC kompatibles Hohlkreisprofil. |
| [HollowRectangleShape](./hollowrectangleshape/) | IFC kompatible hohle rechteckige Form mit sowohl inneren als auch äußeren abgerundeten Ecken. |
| [HShape](./hshape/) | Der [`HShape`](../aspose.threed.profiles/hshape/) liefert die definierenden Parameter einer 'H'- oder 'I'-Form. |
| [LShape](./lshape/) | IFC kompatibles L-förmiges Profil, das durch Parameter definiert ist. |
| [MirroredProfile](./mirroredprofile/) | IFC kompatibles Spiegelprofil. Dieses Profil definiert ein neues Profil, indem das Basisprofil an der y-Achse gespiegelt wird. |
| [ParameterizedProfile](./parameterizedprofile/) | Die Basisklasse aller parametrisierten Profile. |
| [Profile](./profile/) | 2D-Profil in der xy-Ebene |
| [RectangleShape](./rectangleshape/) | IFC kompatible rechteckige Form mit abgerundeten Ecken. |
| [Text](./text/) | Textprofil, dieses Profil beschreibt Konturen mithilfe von Schriftart und Text. |
| [TrapeziumShape](./trapeziumshape/) | IFC kompatible Trapezform, definiert durch Parameter. |
| [TShape](./tshape/) | IFC kompatible T-förmige Form, definiert durch Parameter. |
| [UShape](./ushape/) | IFC kompatible U-förmige Form, definiert durch Parameter. |
| [ZShape](./zshape/) | IFC kompatibles Z-förmiges Profil, definiert durch Parameter. |
