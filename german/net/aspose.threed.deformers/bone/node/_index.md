## Bone.Node property

Gibt den Knoten zurück oder legt ihn fest. Der Knochenknoten ist der Knochen, an dem die Haut befestigt ist, und der [`SkinDeformer`](../../skindeformer/) verwendet den Knochenknoten, um die Verschiebung der Kontrollpunkte zu beeinflussen. Der Knochenknoten hat normalerweise ein [`Skeleton`](../../../aspose.threed.entities/skeleton/) angehängt, aber das ist nicht erforderlich. Das angehängte [`Skeleton`](../../../aspose.threed.entities/skeleton/) wird üblicherweise von DCC-Software verwendet, um dem Benutzer das Skeleton anzuzeigen.

public Node Node { get; set; }
