## GltfSaveOptions.UseCommonMaterials property

Serialisieren Sie Materialien mithilfe der KHR‑Common‑Material‑Erweiterungen, der Standardwert ist false. Wenn Sie dies auf false setzen, führt dies dazu, dass Aspose.3D ein Satz von Vertex/Fragment‑Shadern exportiert, wenn ExportShaders aktiviert ist.

```csharp
public bool UseCommonMaterials { get; set; }
```

## Hinweise

Diese Eigenschaft funktioniert nur für glTF 1.0
