## Discreet3dsLoadOptions.GammaCorrectedColor property

Eine 3ds-Datei kann für dasselbe Attribut Originalfarbe und gamma‑korrigierte Farbe enthalten. Wenn dies auf true gesetzt wird, wird nach Möglichkeit die gamma‑korrigierte Farbe verwendet, andernfalls versucht Aspose.3D, die Originalfarbe zu verwenden.

public bool GammaCorrectedColor { get; set; }
