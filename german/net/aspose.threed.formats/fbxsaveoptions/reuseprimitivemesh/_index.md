## FbxSaveOptions.ReusePrimitiveMesh property

Verwendet das Mesh für Primitive mit denselben Parametern erneut, wodurch die Größe der FBX‑Ausgabe, die aus einer großen Menge primitiver Formen (z. B. aus CAD‑Dateien) erstellt wurde, erheblich reduziert wird. Standardwert ist false

public bool ReusePrimitiveMesh { get; set; }
