## Discreet3dsSaveOptions.HighPreciseColor property

Wenn dies true ist, verwendet die erzeugte 3ds-Datei hochpräzise Farben, d.h. jeder Rot‑/Grün‑/Blau‑Kanal ist ein 32‑Bit‑Float. Andernfalls verwendet die erzeugte Datei 24‑Bit‑Farben, wobei jeder Kanal ein 8‑Bit‑Byte ist. Der Standardwert ist false, weil nicht alle Anwendungen hochpräzise Farben unterstützen.

public bool HighPreciseColor { get; set; }
