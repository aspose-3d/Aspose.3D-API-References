## Discreet3dsSaveOptions.DuplicatedNameSeparator property

Der Trenner zwischen dem Objektnamen und dem duplizierten Zähler, Standardwert ist "_". Wenn die Szene Objekte enthält, die denselben Namen verwenden, erzeugt der Aspose.3D 3DS-Exporter einen anderen Namen für das Objekt. Zum Beispiel gibt es zwei Knoten mit dem Namen "Box"; der erste Knoten hat den Namen "Box", und der zweite Knoten erhält mit der Standardkonfiguration den neuen Namen "Box_2".

```csharp
public string DuplicatedNameSeparator { get; set; }
```
