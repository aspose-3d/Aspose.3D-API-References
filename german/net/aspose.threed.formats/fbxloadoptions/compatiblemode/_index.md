## FbxLoadOptions.CompatibleMode property

Liest oder setzt, ob der Kompatibilitätsmodus aktiviert werden soll. Der Kompatibilitätsmodus versucht, nicht‑standardmäßige FBX‑Definitionen wie von Blender exportierte PBR‑Materialien zu unterstützen. Standardwert ist false.

public bool CompatibleMode { get; set; }
