## FbxLoadOptions.KeepBuiltinGlobalSettings property

Gibt an, ob die eingebauten Eigenschaften in GlobalSettings beibehalten werden sollen, die in [`AssetInfo`](../../../aspose.threed/assetinfo/) durch native Eigenschaften ersetzt werden. Setzen Sie dies auf true, wenn Sie die vollständigen Eigenschaften in GlobalSettings wünschen. Der Standardwert ist false.

```csharp
public bool KeepBuiltinGlobalSettings { get; set; }
```
