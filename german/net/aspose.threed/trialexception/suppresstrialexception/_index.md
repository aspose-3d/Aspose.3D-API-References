## TrialException.SuppressTrialException property

Setzt dies auf true, um die Testausnahme bei unlizenzierter Nutzung zu unterdrücken, aber die Einschränkungen werden nicht aufgehoben. Um die Einschränkungen aufzuheben, verwenden Sie bitte eine gültige Lizenz. Und das Setzen auf true bedeutet außerdem, dass Sie sich der unlizenzierten Einschränkungen bewusst sind.

```csharp
public static bool SuppressTrialException { get; set; }
```
