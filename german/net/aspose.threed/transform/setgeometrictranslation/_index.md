## Transform.SetGeometricTranslation method

Setzt die geometrische Translation. Geometrische Transformation wirkt sich nur auf die angehängten Entitäten aus und lässt die Kindknoten unverändert. Sie wird als lokale Transformation zusammengeführt, wenn Sie die geometrische Transformation in Dateitypen exportieren, die sie nicht unterstützen.

```csharp
public Transform SetGeometricTranslation(double x, double y, double z)
```

## Beispiele

```csharp
Node node = new Node();
node.Transform.SetGeometricTranslation(10, 0, 0);
```
