## PbrSpecularMaterial.Transparency property

Liest oder setzt den Transparenzfaktor. Der Faktor sollte im Bereich zwischen 0 (0 %, vollständig undurchsichtig) und 1 (100 %, vollständig transparent) liegen. Jeder ungültige Faktorwert wird abgeschnitten.

```csharp
public double Transparency { get; set; }
```

### Property Value
