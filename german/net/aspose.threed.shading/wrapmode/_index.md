## WrapMode enumeration

Wrap-Modus der Textur.

```csharp
public enum WrapMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Wrap | `0` | Kachelt die Textur auf der Oberfläche des Modells und erzeugt ein wiederholendes Muster. |
| Clamp | `1` | Klemmt die Textur am letzten Pixel am Rand. |
| Mirror | `2` | Die Textur wird wiederholt, aber sie wird gespiegelt, wenn der ganzzahlige Teil der Koordinate ungerade ist. |
| MirrorOnce | `3` | Die Textur wird einmal gespiegelt und dann an den Maximalwert geklemmt. |
| Border | `4` | Die Koordinaten, die außerhalb des Bereichs [0.0, 1.0] liegen, werden auf eine angegebene Randfarbe gesetzt. |
