सभी यूटिलिटी क्लासेस इस नामस्थान में परिभाषित हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [FileSystem](./filesystem/) | फ़ाइल सिस्टम एन्कैप्सुलेशन। Aspose.3D इसका उपयोग निर्भरताओं को पढ़ने/लिखने के लिए करेगा। |
| [IOExtension](./ioextension/) | मैट्रिक्स/वेक्टर को बाइनरी राइटर में लिखने के लिए उपयोगिताएँ। |
| [MathUtils](./mathutils/) | उपयोगी गणितीय उपयोगिताओं का एक सेट। |
| [ParseException](./parseexception/) | जब Aspose.3D इनपुट को पार्स करने में विफल रहता है तो अपवाद। |
| [SemanticAttribute](./semanticattribute/) | उपयोगकर्ता को अपने स्वयं के स्ट्रक्चर का उपयोग करने की अनुमति दें स्थिर घोषणा के लिए [`VertexDeclaration`](../aspose.threed.utilities/vertexdeclaration/) |
| [TransformBuilder](./transformbuilder/) | यह [`TransformBuilder`](../aspose.threed.utilities/transformbuilder/) ट्रांसफ़ॉर्म मैट्रिक्स को ट्रांसफ़ॉर्मेशन की श्रृंखला द्वारा बनाने के लिए उपयोग किया जाता है। |
| [Vertex](./vertex/) | वर्टेक्स रेफ़रेंस, जिसका उपयोग [`TriMesh`](../aspose.threed.entities/trimesh/) में कच्चे वर्टेक्स तक पहुँचने के लिए किया जाता है। |
| [VertexDeclaration](./vertexdeclaration/) | कस्टम परिभाषित वर्टेक्स संरचना की घोषणा। |
| [VertexField](./vertexfield/) | वर्टेक्स के फ़ील्ड मेमोरी लेआउट का विवरण। |
| [Watermark](./watermark/) | मेश से/तक ब्लाइंड वॉटरमार्क को एन्कोड/डिकोड करने के लिए उपयोगिता। |

| [FVector4](./fvector4/) | चार घटकों वाला फ़्लोट वेक्टर। |

| [Vector2](./vector2/) | दो घटकों वाला एक वेक्टर। |
| [Vector3](./vector3/) | तीन घटकों वाला एक वेक्टर। |
