## Patch class

A `Patch` एक पैरामीट्रिक मॉडलिंग सतह है, जो [`NurbsSurface`](../nurbssurface/) के समान है, यह दो [`PatchDirection`](../patchdirection/) द्वारा भी परिभाषित है, अर्थात [`U`](./u/) और [`V`](./v/)। लेकिन `Patch` और [`NurbsSurface`](../nurbssurface/) के बीच अंतर यह है कि [`PatchDirection`](../patchdirection/) वक्र Bezier, QuadraticBezier, BasisSpline, CardinalSpline और Linear में से कोई एक हो सकता है।

```csharp
public class Patch : Geometry
```
