सभी 2D प्रोफ़ाइल क्लासेस इस नामस्थान में परिभाषित हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [ArbitraryProfile](./arbitraryprofile/) | यह क्लास आपको मनमाने वक्र से सीधे 2D प्रोफ़ाइल बनाने की अनुमति देती है। |
| [CenterLineProfile](./centerlineprofile/) | IFC संगत सेंटर लाइन प्रोफ़ाइल |
| [CircleShape](./circleshape/) | IFC संगत सर्कल प्रोफ़ाइल, जिसे [`LinearExtrusion`](../aspose.threed.entities/linearextrusion/) के माध्यम से मेष बनाने के लिए उपयोग किया जा सकता है |
| [CShape](./cshape/) | IFC संगत C-आकार प्रोफ़ाइल जो पैरामीटरों द्वारा परिभाषित है। प्रोफ़ाइल की केंद्र स्थिति बाउंडिंग बॉक्स के केंद्र में है। |
| [EllipseShape](./ellipseshape/) | IFC संगत एलिप्स आकार जो पैरामीटरों द्वारा परिभाषित है। प्रोफ़ाइल की केंद्र स्थिति बाउंडिंग बॉक्स के केंद्र में है। |
| [FontFile](./fontfile/) | फ़ॉन्ट फ़ाइल में ग्लिफ़ की परिभाषाएँ होती हैं, इसका उपयोग टेक्स्ट प्रोफ़ाइल बनाने के लिए किया जाता है। |
| [HollowCircleShape](./hollowcircleshape/) | IFC संगत खोखला सर्कल प्रोफ़ाइल। |
| [HollowRectangleShape](./hollowrectangleshape/) | IFC संगत खोखला आयताकार आकार जिसमें अंदरूनी/बाहरी गोल कोने दोनों हैं। |
| [HShape](./hshape/) | यह [`HShape`](../aspose.threed.profiles/hshape/) 'H' या 'I' आकार के परिभाषित पैरामीटर प्रदान करता है। |
| [LShape](./lshape/) | IFC संगत L-आकार प्रोफ़ाइल जो पैरामीटरों द्वारा परिभाषित है। |
| [MirroredProfile](./mirroredprofile/) | IFC संगत मिरर प्रोफ़ाइल। यह प्रोफ़ाइल बेस प्रोफ़ाइल को y-अक्ष के बारे में मिरर करके एक नई प्रोफ़ाइल परिभाषित करती है। |
| [ParameterizedProfile](./parameterizedprofile/) | सभी पैरामीटराइज्ड प्रोफ़ाइलों की बेस क्लास। |
| [Profile](./profile/) | xy तल में 2D प्रोफ़ाइल |
| [RectangleShape](./rectangleshape/) | IFC संगत आयताकार आकार गोल कोनों के साथ। |
| [Text](./text/) | टेक्स्ट प्रोफ़ाइल, यह प्रोफ़ाइल फ़ॉन्ट और टेक्स्ट का उपयोग करके कंटूर का वर्णन करती है। |
| [TrapeziumShape](./trapeziumshape/) | IFC संगत ट्रैपेज़ियम आकार पैरामीटर द्वारा परिभाषित। |
| [TShape](./tshape/) | IFC संगत T-आकार पैरामीटर द्वारा परिभाषित। |
| [UShape](./ushape/) | IFC संगत U-आकार पैरामीटर द्वारा परिभाषित। |
| [ZShape](./zshape/) | IFC संगत Z-आकार प्रोफ़ाइल पैरामीटर द्वारा परिभाषित। |
