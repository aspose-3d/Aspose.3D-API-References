## Bone.Node property

Λαμβάνει ή ορίζει τον κόμβο. Ο κόμβος οστού είναι το οστό στο οποίο συνδέεται το δέρμα, το [`SkinDeformer`](../../skindeformer/) θα χρησιμοποιήσει τον κόμβο οστού για να επηρεάσει τη μετατόπιση των σημείων ελέγχου. Ο κόμβος οστού συνήθως έχει ένα [`Skeleton`](../../../aspose.threed.entities/skeleton/) συνημμένο, αλλά δεν είναι υποχρεωτικό. Το συνημμένο [`Skeleton`](../../../aspose.threed.entities/skeleton/) χρησιμοποιείται συνήθως από το λογισμικό DCC για να εμφανίσει το σκελετό στον χρήστη.

```csharp
public Node Node { get; set; }
```
