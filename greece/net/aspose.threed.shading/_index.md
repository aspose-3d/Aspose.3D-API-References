Όλες οι κλάσεις που σχετίζονται με το shading ορίζονται σε αυτόν τον χώρο ονομάτων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [LambertMaterial](./lambertmaterial/) | Υλικό για το μοντέλο σκίασης Lambert |
| [Material](./material/) | Το υλικό ορίζει τις παραμέτρους που απαιτούνται για την οπτική εμφάνιση της γεωμετρίας. Το Aspose.3D παρέχει μοντέλο σκίασης για [`LambertMaterial`](../aspose.threed.shading/lambertmaterial/), [`PhongMaterial`](../aspose.threed.shading/phongmaterial/) και [`ShaderMaterial`](../aspose.threed.shading/shadermaterial/) |
| [PbrMaterial](./pbrmaterial/) | Υλικό για φυσικά βασισμένη απόδοση βασισμένο σε χρώμα αλμπέτο, μεταλλικό και τραχύτητα |
| [PbrSpecularMaterial](./pbrspecularmaterial/) | Υλικό για φυσικά βασισμένη απόδοση βασισμένο σε διαχυτικό χρώμα, κατοπτρικό και γυαλάδα |
| [PhongMaterial](./phongmaterial/) | Υλικό για το μοντέλο σκίασης Blinn-Phong. |
| [ShaderMaterial](./shadermaterial/) | Ένα υλικό shader επιτρέπει την περιγραφή του υλικού από εξωτερική μηχανή απόδοσης ή γλώσσα shader. [`ShaderMaterial`](../aspose.threed.shading/shadermaterial/) χρησιμοποιεί το [`ShaderTechnique`](../aspose.threed.shading/shadertechnique/) για να περιγράψει τις συγκεκριμένες λεπτομέρειες απόδοσης, και το πιο κατάλληλο θα χρησιμοποιηθεί ανάλογα με την τελική πλατφόρμα απόδοσης. Για παράδειγμα, η παρουσίαση του [`ShaderMaterial`](../aspose.threed.shading/shadermaterial/) μπορεί να έχει δύο τεχνικές, η μία ορίζεται από HLSL και η άλλη από GLSL. Σε πλατφόρμα χωρίς παράθυρο, το GLSL πρέπει να χρησιμοποιείται αντί του HLSL |
| [ShaderTechnique](./shadertechnique/) | Μια τεχνική shader αντιπροσωπεύει μια συγκεκριμένη υλοποίηση απόδοσης. |
| [Texture](./texture/) | Αυτή η κλάση ορίζει την υφή από ένα εξωτερικό αρχείο. |
| [TextureBase](./texturebase/) | Βασική κλάση για όλες τις συγκεκριμένες υφές. Η υφή ορίζει την εμφάνιση και την αίσθηση μιας επιφάνειας γεωμετρίας. |
| [TextureSlot](./textureslot/) | Θέση υφής στο [`Material`](../aspose.threed.shading/material/), μπορεί να απαριθμηθεί μέσω της παρουσίασης του υλικού. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [AlphaSource](./alphasource/) | Ορίζει εάν η υφή περιέχει το κανάλι άλφα. |
| [TextureFilter](./texturefilter/) | Επιλογές φίλτρου κατά τη δειγματοληψία της υφής. |
| [WrapMode](./wrapmode/) | Λειτουργία περιτύλιξης της υφής. |
