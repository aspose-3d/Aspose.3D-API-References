## VertexElement class

Βασική κλάση των στοιχείων κορυφής. Ένας τύπος στοιχείου κορυφής προσδιορίζεται από το VertexElementType. Ένα VertexElement περιγράφει πώς το στοιχείο κορυφής αντιστοιχίζεται σε μια επιφάνεια γεωμετρίας και πώς οι πληροφορίες αντιστοίχισης διατάσσονται στη μνήμη. Ένα VertexElement περιέχει Normals, UVs ή άλλου είδους πληροφορίες.

public abstract class VertexElement : IIndexedVertexElement
