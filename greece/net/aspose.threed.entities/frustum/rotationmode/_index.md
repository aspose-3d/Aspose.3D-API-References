## Frustum.RotationMode property

Λαμβάνει ή ορίζει τη λειτουργία προσανατολισμού του frustum. Αυτή η ιδιότητα λειτουργεί μόνο όταν το [`Target`](../target/) είναι null. Εάν η τιμή είναι FixedTarget, η κατεύθυνση υπολογίζεται πάντα από την ιδιότητα [`LookAt`](../lookat/). Διαφορετικά, το [`LookAt`](../lookat/) υπολογίζεται πάντα από το [`Direction`](../direction/).

```csharp
public RotationMode RotationMode { get; set; }
```
