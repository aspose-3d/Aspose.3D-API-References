## AnimationChannel.DefaultValue property

Λαμβάνει ή ορίζει την Default τιμή του καναλιού. Εάν ένα κανάλι δεν έχει συνδεδεμένες ακολουθίες keyframe, η προεπιλεγμένη τιμή θα χρησιμοποιηθεί κατά την αξιολόγηση της animation. Ένα πραγματικό σενάριο: Η animation αναπαριστά μόνο τη συντεταγμένη x ενός κόμβου, οι y και z δεν αλλάζουν, τότε η προεπιλεγμένη τιμή θα χρησιμοποιηθεί κατά την πλήρη αξιολόγηση της μετάφρασης.

```csharp
public object DefaultValue { get; set; }
```
