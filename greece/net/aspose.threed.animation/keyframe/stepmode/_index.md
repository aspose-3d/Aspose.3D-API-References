## KeyFrame.StepMode property

Λαμβάνει ή ορίζει τη λειτουργία βήματος του καρέ‑κλειδιού. Εάν ο τύπος παρεμβολής είναι Constant, η list.data[index] αποφασίζει ποια τιμή καρέ‑κλειδιού θα χρησιμοποιηθεί κατά την παρεμβολή. Μια PreviousValue σημαίνει ότι θα χρησιμοποιηθεί η τιμή του αριστερού καρέ‑κλειδιού. Μια NextValue σημαίνει ότι θα χρησιμοποιηθεί η τιμή του επόμενου δεξιού καρέ‑κλειδιού.

```csharp
public StepMode StepMode { get; set; }
```

### Property Value

Η λειτουργία βήματος.
