## AssetInfo class

Πληροφορίες του περιουσιακού στοιχείου. Οι πληροφορίες του περιουσιακού στοιχείου μπορούν να προσαρτηθούν σε ένα [`Scene`](../scene/). Η θυγατρική [`Scene`](../scene/) μπορεί να έχει το δικό της `AssetInfo` για να παρακάμψει τον ορισμό του γονέα.

```csharp
public class AssetInfo : A3DObject
```

## Παραδείγματα

Ο παρακάτω κώδικας δείχνει πώς να διαβάσετε τις πληροφορίες του στοιχείου από ένα αρχείο fbx:

```csharp
Scene scene = Scene.FromFile("test.fbx");
Console.WriteLine($"The file is created at {scene.AssetInfo.CreationTime} by {scene.AssetInfo.ApplicationName} {scene.AssetInfo.ApplicationVersion} ");
```
