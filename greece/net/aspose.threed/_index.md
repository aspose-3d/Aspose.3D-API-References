Ο βασικός χώρος ονομάτων του Aspose.3D

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [A3DObject](./a3dobject/) | Η βασική κλάση όλων των αντικειμένων Aspose.ThreeD, όλες οι υποκλάσεις θα υποστηρίζουν δυναμικές ιδιότητες. |
| [AssetInfo](./assetinfo/) | Πληροφορίες του περιουσιακού στοιχείου. Οι πληροφορίες του περιουσιακού στοιχείου μπορούν να προσαρτηθούν σε ένα [`Scene`](../aspose.threed/scene/). Ένα παιδικό [`Scene`](../aspose.threed/scene/) μπορεί να έχει το δικό του [`AssetInfo`](../aspose.threed/assetinfo/) για να παρακάμψει τον ορισμό του γονέα. |
| [AxisSystem](./axissystem/) | Το σύστημα αξόνων είναι ένας συνδυασμός του συστήματος συντεταγμένων, του διανύσματος προς τα πάνω και του διανύσματος προς τα εμπρός. |
| [BonePose](./bonepose/) | Το [`BonePose`](../aspose.threed/bonepose/) περιέχει τον πίνακα μετασχηματισμού για έναν κόμβο οστού |
| [CustomObject](./customobject/) | Τα μεταδεδομένα ή τα προσαρμοσμένα αντικείμενα που χρησιμοποιούνται σε αρχεία 3D διαχειρίζονται από αυτήν την κλάση. Όλες οι προσαρμοσμένες ιδιότητες αποθηκεύονται ως δυναμικές ιδιότητες. |
| [Entity](./entity/) | Η βασική κλάση όλων των οντοτήτων. Η οντότητα αντιπροσωπεύει ένα συγκεκριμένο αντικείμενο που συνδέεται κάτω από έναν κόμβο όπως το [`Light`](../aspose.threed.entities/light/)/[`Geometry`](../aspose.threed.entities/geometry/). |
| [ExportException](./exportexception/) | Εξαιρέσεις όταν το Aspose.3D απέτυχε να εξάγει τη σκηνή σε αρχείο |
| [FileFormat](./fileformat/) | Ορισμός μορφής αρχείου |
| [FileFormatType](./fileformattype/) | Τύπος μορφής αρχείου |
| [GlobalTransform](./globaltransform/) | Η καθολική μετατροπή είναι παρόμοια με το [`Transform`](../aspose.threed/transform/) αλλά είναι αμετάβλητη ενώ αντιπροσωπεύει τον τελικό αξιολογημένο μετασχηματισμό. Χρησιμοποιείται σύστημα συντεταγμένων δεξιού χεριού κατά την αξιολόγηση της καθολικής μετατροπής |
| [Group](./group/) | Ένα [`Group`](../aspose.threed/group/) αντιπροσωπεύει τις λογικές σχέσεις του [`Node`](../aspose.threed/node/). |
| [ImageRenderOptions](./imagerenderoptions/) | Επιλογές για το [`Render`](../aspose.threed/scene/render/) και το [`Render`](../aspose.threed/scene/render/) |
| [ImportException](./importexception/) | Εξαίρεση όταν το Aspose.3D απέτυχε να ανοίξει την καθορισμένη πηγή |
| [License](./license/) | Παρέχει μεθόδους για την αδειοδότηση του στοιχείου. |
| [Metered](./metered/) | Παρέχει μεθόδους για τον ορισμό κλειδιού μέτρησης. |
| [Node](./node/) | Αντιπροσωπεύει ένα στοιχείο στο γράφημα σκηνής. Ένα γράφημα σκηνής είναι ένα δέντρο αντικειμένων Node. Οι υπηρεσίες διαχείρισης του δέντρου είναι ενσωματωμένες σε αυτήν την κλάση. Σημειώστε ότι το Aspose.3D SDK δεν ελέγχει την εγκυρότητα του κατασκευασμένου γραφήματος σκηνής. Είναι ευθύνη του καλούντος να διασφαλίσει ότι δεν δημιουργεί κυκλικά γραφήματα σε μια ιεραρχία κόμβων. Εκτός από τη διαχείριση του δέντρου, αυτή η κλάση ορίζει όλες τις ιδιότητες που απαιτούνται για την περιγραφή της θέσης του αντικειμένου στη σκηνή. Αυτές οι πληροφορίες περιλαμβάνουν τις βασικές ιδιότητες Μετάφρασης, Περιστροφής και Κλιμάκωσης καθώς και τις πιο προχωρημένες επιλογές για άξονες, όρια και χαρακτηριστικά αρθρώσεων IK όπως η σκληρότητα και η αποσβέση. Όταν δημιουργείται για πρώτη φορά, το αντικείμενο Node είναι "κενό" (δηλαδή: είναι ένα αντικείμενο χωρίς καμία γραφική αναπαράσταση που περιέχει μόνο τις πληροφορίες θέσης). Σε αυτήν την κατάσταση, μπορεί να χρησιμοποιηθεί για την αναπαράσταση γονέων στη δομή δέντρου κόμβων, αλλά όχι πολύ περισσότερο. Η κανονική χρήση αυτού του τύπου αντικειμένων είναι να τους προστεθεί μια οντότητα που θα εξειδικεύσει τον κόμβο (δείτε την "Entity"). Η οντότητα είναι ένα αντικείμενο από μόνη της και είναι συνδεδεμένη με το Node. Αυτό επίσης σημαίνει ότι η ίδια οντότητα μπορεί να μοιραστεί μεταξύ πολλών κόμβων. Η Camera, το Light, το Mesh κ.λπ. είναι όλες οντότητες και όλες προέρχονται από τη βασική κλάση Entity. |
| [NodeVisitor](./nodevisitor/) | Μια κλήση επιστροφής για να διασχίσει ολόκληρη την ιεραρχία των κόμβων. |
| [Pose](./pose/) | Η pose χρησιμοποιείται για την αποθήκευση του πίνακα μετασχηματισμού όταν η γεωμετρία είναι ενσωματωμένη. Η pose είναι ένα σύνολο από [`BonePose`](../aspose.threed/bonepose/), κάθε [`BonePose`](../aspose.threed/bonepose/) αποθηκεύει τις συγκεκριμένες πληροφορίες μετασχηματισμού του κόμβου οστού. |
| [Property](./property/) | Κλάση για την αποθήκευση ιδιοτήτων που ορίζονται από τον χρήστη. |
| [PropertyCollection](./propertycollection/) | Η συλλογή των ιδιοτήτων |
| [Scene](./scene/) | Μια σκηνή είναι ένα αντικείμενο ανώτερου επιπέδου που περιέχει τους κόμβους, τις γεωμετρίες, τα υλικά, τις υφές, την κίνηση, τις στάσεις, τις υπο-σκηνές κ.λπ. Η σκηνή μπορεί να έχει υπο-σκηνές, λειτουργεί ως υποστήριξη πολλαπλών εγγράφων σε αρχεία όπως collada/blender/fbx. Η ιεραρχία των κόμβων μπορεί να προσπελαστεί μέσω του [`RootNode`](../aspose.threed/scene/rootnode/). Το [`Library`](../aspose.threed/scene/library/) χρησιμοποιείται για τη διατήρηση αναφοράς σε μη συνδεδεμένα αντικείμενα κατά τη σειριοποίηση (όπως μεταδεδομένα ή προσαρμοσμένα αντικείμενα), ώστε να μπορεί να χρησιμοποιηθεί ως βιβλιοθήκη. |
| [SceneObject](./sceneobject/) | Η ριζική κλάση των αντικειμένων που θα αποθηκευτούν μέσα σε μια σκηνή. |
| [Transform](./transform/) | Ένας μετασχηματισμός περιέχει πληροφορίες που επιτρέπουν την πρόσβαση στη μετάφραση/κλιμάκωση/περιστροφή του αντικειμένου ή στον πίνακα μετασχηματισμού με ελάχιστο κόστος. Αυτό χρησιμοποιείται από τον τοπικό μετασχηματισμό. |
| [TrialException](./trialexception/) | Αυτό ενεργοποιείται στο Scene.Open/Scene.Save όταν δεν έχουν εφαρμοστεί άδειες. Μπορείτε να απενεργοποιήσετε αυτήν την εξαίρεση ορίζοντας το SuppressTrialException σε true. |
