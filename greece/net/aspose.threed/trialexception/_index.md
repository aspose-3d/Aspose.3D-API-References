## TrialException class

Αυτό ενεργοποιείται στο Scene.Open/Scene.Save όταν δεν έχουν εφαρμοστεί άδειες. Μπορείτε να απενεργοποιήσετε αυτήν την εξαίρεση ορίζοντας το SuppressTrialException σε true.

```csharp
public class TrialException : Exception
```
