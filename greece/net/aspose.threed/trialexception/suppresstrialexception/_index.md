## TrialException.SuppressTrialException property

Ορίζει αυτό σε true για να καταστεί λογοκριμένη η δοκιμαστική εξαίρεση κατά τη χρήση χωρίς άδεια, αλλά οι περιορισμοί δεν θα αφαιρεθούν. Για να αφαιρεθούν οι περιορισμοί, παρακαλούμε χρησιμοποιήστε μια έγκυρη άδεια. Η ρύθμιση αυτή σε true σημαίνει επίσης ότι γνωρίζετε τους περιορισμούς χωρίς άδεια.

```csharp
public static bool SuppressTrialException { get; set; }
```
