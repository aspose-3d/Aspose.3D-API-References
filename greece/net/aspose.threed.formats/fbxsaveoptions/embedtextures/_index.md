## FbxSaveOptions.EmbedTextures property

Λαμβάνει ή ορίζει αν θα ενσωματωθεί η υφή στο τελικό αρχείο εξόδου. Ο FBX Exporter θα προσπαθήσει να βρει τα ακατέργαστα δεδομένα της υφής από [`FileSystem`](../../ioconfig/filesystem/), και να ενσωματώσει το αρχείο στο τελικό αρχείο FBX. Η προεπιλεγμένη τιμή είναι false.

```csharp
public bool EmbedTextures { get; set; }
```
