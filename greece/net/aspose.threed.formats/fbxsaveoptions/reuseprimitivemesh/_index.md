## FbxSaveOptions.ReusePrimitiveMesh property

Επαναχρησιμοποίηση του πλέγματος για τα primitives με τις ίδιες παραμέτρους, αυτό θα μειώσει σημαντικά το μέγεθος του εξόδου FBX, όπου η σκηνή κατασκευάστηκε από μεγάλο σύνολο πρωτόγονων σχημάτων (όπως εισαγόμενα από αρχεία CAD). Η προεπιλεγμένη τιμή είναι ψευδής.

```csharp
public bool ReusePrimitiveMesh { get; set; }
```
