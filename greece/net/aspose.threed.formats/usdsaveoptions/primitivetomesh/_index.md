## UsdSaveOptions.PrimitiveToMesh property

Μετατρέψτε τις πρωτόγονες οντότητες σε πλέγμα κατά την εξαγωγή. Ή κωδικοποιήστε απευθείας τις πρωτόγονες στο αρχείο εξόδου (θα χρησιμοποιηθεί ο ορισμός επέκτασης της Aspose για ανεπίσημες πρωτόγονες όπως Dish, Torus). Η προεπιλεγμένη τιμή είναι true.

```csharp
public bool PrimitiveToMesh { get; set; }
```
