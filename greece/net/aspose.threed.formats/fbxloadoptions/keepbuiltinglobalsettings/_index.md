## FbxLoadOptions.KeepBuiltinGlobalSettings property

Λαμβάνει ή ορίζει εάν να διατηρηθούν οι ενσωματωμένες ιδιότητες στο GlobalSettings που έχουν αντικατάσταση ιδιότητας σε [`AssetInfo`](../../../aspose.threed/assetinfo/). Ορίστε το σε true εάν θέλετε τις πλήρεις ιδιότητες στο GlobalSettings. Η προεπιλεγμένη τιμή είναι false

```csharp
public bool KeepBuiltinGlobalSettings { get; set; }
```
