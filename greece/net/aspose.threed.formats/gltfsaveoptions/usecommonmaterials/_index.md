## GltfSaveOptions.UseCommonMaterials property

Σειριοποιεί τα υλικά χρησιμοποιώντας τις κοινές επεκτάσεις υλικού KHR, η προεπιλεγμένη τιμή είναι false. Ορίζοντας αυτό σε false θα κάνει το Aspose.3D να εξάγει ένα σύνολο σκίασης κορυφής/κατακερματισμού εάν ExportShaders.

```csharp
public bool UseCommonMaterials { get; set; }
```
