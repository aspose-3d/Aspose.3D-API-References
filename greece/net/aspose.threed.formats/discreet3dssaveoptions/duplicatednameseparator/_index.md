## Discreet3dsSaveOptions.DuplicatedNameSeparator property

Ο διαχωριστής μεταξύ του ονόματος του αντικειμένου και του διπλότυπου μετρητή, η προεπιλεγμένη τιμή είναι "_". Όταν η σκηνή περιέχει αντικείμενα που χρησιμοποιούν το ίδιο όνομα, ο εξαγωγέας 3DS του Aspose.3D θα δημιουργήσει διαφορετικό όνομα για το αντικείμενο. Για παράδειγμα, υπάρχουν δύο κόμβοι με όνομα "Box", ο πρώτος κόμβος θα έχει το όνομα "Box", και ο δεύτερος κόμβος θα λάβει νέο όνομα "Box_2" χρησιμοποιώντας την προεπιλεγμένη διαμόρφωση.

```csharp
public string DuplicatedNameSeparator { get; set; }
```
