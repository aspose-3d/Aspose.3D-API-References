## Discreet3dsSaveOptions.HighPreciseColor property

Αν αυτό είναι true, το παραγόμενο αρχείο 3ds θα χρησιμοποιεί χρώμα υψηλής ακρίβειας, δηλαδή κάθε κανάλι κόκκινο/πράσινο/μπλε είναι σε 32-bit float. Διαφορετικά, το παραγόμενο αρχείο θα χρησιμοποιεί χρώμα 24-bit, κάθε κανάλι χρησιμοποιεί 8-bit byte. Η προεπιλεγμένη τιμή είναι false, επειδή δεν υποστηρίζουν όλες οι εφαρμογές το χρώμα υψηλής ακρίβειας.

```csharp
public bool HighPreciseColor { get; set; }
```
