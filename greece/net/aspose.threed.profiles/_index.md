Όλες οι κλάσεις προφίλ 2D ορίζονται σε αυτόν τον χώρο ονομάτων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ArbitraryProfile](./arbitraryprofile/) | Αυτή η κλάση σας επιτρέπει να δημιουργήσετε ένα προφίλ 2D απευθείας από αυθαίρετη καμπύλη. |
| [CenterLineProfile](./centerlineprofile/) | Προφίλ κεντρικής γραμμής συμβατό με IFC |
| [CircleShape](./circleshape/) | Προφίλ κύκλου συμβατό με IFC, το οποίο μπορεί να χρησιμοποιηθεί για τη δημιουργία ενός πλέγματος μέσω του [`LinearExtrusion`](../aspose.threed.entities/linearextrusion/) |
| [CShape](./cshape/) | Προφίλ σχήματος C συμβατό με IFC που ορίζεται από παραμέτρους. Η κεντρική θέση του προφίλ βρίσκεται στο κέντρο του περιοριστικού πλαισίου. |
| [EllipseShape](./ellipseshape/) | Σχήμα έλλειψης συμβατό με IFC που ορίζεται από παραμέτρους. Η κεντρική θέση του προφίλ βρίσκεται στο κέντρο του περιοριστικού πλαισίου. |
| [FontFile](./fontfile/) | Το αρχείο γραμματοσειράς περιέχει ορισμούς για γλύφους, το οποίο χρησιμοποιείται για τη δημιουργία προφίλ κειμένου. |
| [HollowCircleShape](./hollowcircleshape/) | Προφίλ κενού κύκλου συμβατό με IFC. |
| [HollowRectangleShape](./hollowrectangleshape/) | Σχήμα κενού ορθογωνίου συμβατό με IFC με στρογγυλεμένες εσωτερικές/εξωτερικές γωνίες. |
| [HShape](./hshape/) | Το [`HShape`](../aspose.threed.profiles/hshape/) παρέχει τις καθοριστικές παραμέτρους ενός σχήματος 'H' ή 'I'. |
| [LShape](./lshape/) | Προφίλ σχήματος L συμβατό με IFC που ορίζεται από παραμέτρους. |
| [MirroredProfile](./mirroredprofile/) | Προφίλ καθρεπτισμού συμβατό με IFC. Αυτό το προφίλ ορίζει ένα νέο προφίλ αντικατοπτρίζοντας το βασικό προφίλ γύρω από τον άξονα y. |
| [ParameterizedProfile](./parameterizedprofile/) | Η βασική κλάση όλων των παραμετρικών προφίλ. |
| [Profile](./profile/) | 2D προφίλ στο επίπεδο xy |
| [RectangleShape](./rectangleshape/) | Συμβατό με IFC ορθογώνιο σχήμα με στρογγυλεμένες γωνίες. |
| [Text](./text/) | Προφίλ κειμένου, αυτό το προφίλ περιγράφει τα περιγράμματα χρησιμοποιώντας γραμματοσειρά και κείμενο. |
| [TrapeziumShape](./trapeziumshape/) | Συμβατό με IFC σχήμα τραπεζίου ορισμένο από παραμέτρους. |
| [TShape](./tshape/) | Συμβατό με IFC σχήμα T ορισμένο από παραμέτρους. |
| [UShape](./ushape/) | Συμβατό με IFC σχήμα U ορισμένο από παραμέτρους. |
| [ZShape](./zshape/) | Συμβατό με IFC προφίλ σχήματος Z ορισμένο από παραμέτρους. |
