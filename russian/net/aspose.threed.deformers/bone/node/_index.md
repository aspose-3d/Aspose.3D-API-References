## Bone.Node property

Получает или задает узел. Узел кости — это кость, к которой прикреплена кожа; [`SkinDeformer`](../../skindeformer/) будет использовать узел кости для влияния на смещение контрольных точек. Обычно у узла кости есть прикреплённый [`Skeleton`](../../../aspose.threed.entities/skeleton/), но это не обязательно. Прикреплённый [`Skeleton`](../../../aspose.threed.entities/skeleton/) обычно используется программным обеспечением DCC для отображения скелета пользователю.

```csharp
public Node Node { get; set; }
```
