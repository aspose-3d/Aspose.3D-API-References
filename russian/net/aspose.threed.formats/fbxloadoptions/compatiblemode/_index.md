## FbxLoadOptions.CompatibleMode property

Получает или задает, включить ли совместимый режим. Совместимый режим будет пытаться поддерживать нестандартные определения FBX, такие как PBR-материалы, экспортированные из Blender. Значение по умолчанию — false.

```csharp
public bool CompatibleMode { get; set; }
```
