## GltfSaveOptions.BufferFile property

Имя файла внешнего буферного файла, используемого для хранения бинарных данных. Если этот файл не указан, Aspose.3D сгенерирует имя автоматически. Это игнорируется при экспорте glTF в бинарном режиме.

```csharp
public string BufferFile { get; set; }
```
