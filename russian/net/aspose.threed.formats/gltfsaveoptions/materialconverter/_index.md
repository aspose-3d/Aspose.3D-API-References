## GltfSaveOptions.MaterialConverter property

Пользовательский конвертер для преобразования материала геометрии в материал PBR. Если он не задан, экспортёр glTF 2.0 автоматически преобразует стандартный материал в материал PBR. Значение по умолчанию — null. Это свойство используется при экспорте сцены в файл glTF 2.0.

```csharp
public MaterialConverter MaterialConverter { get; set; }
```
