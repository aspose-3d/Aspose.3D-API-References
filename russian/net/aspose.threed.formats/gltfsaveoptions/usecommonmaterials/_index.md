## GltfSaveOptions.UseCommonMaterials property

Сериализовать материалы с использованием общих расширений материалов KHR, значение по умолчанию — false. Установка этого параметра в false приведёт к тому, что Aspose.3D экспортирует набор вершинных/фрагментных шейдеров, если включён ExportShaders.

```csharp
public bool UseCommonMaterials { get; set; }
```

## Примечания

Это свойство работает только с glTF 1.0
