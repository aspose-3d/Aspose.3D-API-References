## GltfSaveOptions.ImageFormat property

Стандартный glTF поддерживает только PNG/JPG в качестве формата текстур, эта опция определяет, как Aspose.3D будет конвертировать нестандартные изображения в поддерживаемый формат во время экспорта. Значение по умолчанию — Png.

```csharp
public GltfEmbeddedImageFormat ImageFormat { get; set; }
```
