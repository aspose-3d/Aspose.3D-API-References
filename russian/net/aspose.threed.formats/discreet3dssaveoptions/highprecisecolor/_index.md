## Discreet3dsSaveOptions.HighPreciseColor property

Если параметр установлен в true, сгенерированный файл 3ds будет использовать высокоточный цвет, то есть каждый канал красного/зелёного/синего будет представлен 32‑битным float. В противном случае файл будет использовать 24‑битный цвет, каждый канал — 8‑битный байт. Значение по умолчанию — false, поскольку не все приложения поддерживают высокоточный цвет.

```csharp
public bool HighPreciseColor { get; set; }
```
