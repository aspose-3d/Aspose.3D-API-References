## Discreet3dsSaveOptions.DuplicatedNameSeparator property

Разделитель между именем объекта и счётчиком дублирования, значение по умолчанию — "_". Когда сцена содержит объекты с одинаковым именем, экспортер Aspose.3D 3DS генерирует другое имя для объекта. Например, есть два узла с именем "Box": первый узел будет иметь имя "Box", а второй получит новое имя "Box_2" при использовании конфигурации по умолчанию.

```csharp
public string DuplicatedNameSeparator { get; set; }
```
