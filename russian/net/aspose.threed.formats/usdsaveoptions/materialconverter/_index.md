## UsdSaveOptions.MaterialConverter property

Пользовательский конвертер для преобразования материала геометрии в материал PBR. Если он не назначен, экспортёр USD автоматически преобразует стандартный материал в материал PBR. Значение по умолчанию — null.

public MaterialConverter MaterialConverter { get; set; }
