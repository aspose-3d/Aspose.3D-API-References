## PdfRenderMode enumeration

Render mode указывает стиль, в котором рендерится 3D‑артворк.

```csharp
public enum PdfRenderMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Solid | `0` | Отображает текстурированные и освещённые геометрические формы. |
| SolidWireframe | `1` | Отображает текстурированные и освещённые геометрические формы (треугольники) с одноцветными ребрами поверх них. |
| Transparent | `2` | Отображает текстурированные и освещённые геометрические формы (треугольники) с добавленным уровнем прозрачности. |
| TransparentWireframe | `3` | Отображает текстурированные и освещённые геометрические формы (треугольники) с добавленным уровнем прозрачности, с одноцветными непрозрачными ребрами поверх них. |
| BoundingBox | `4` | Отображает ребра ограничивающего коробки каждого узла, выровненные по осям локального координатного пространства этого узла. |
| TransparentBoundingBox | `5` | Отображает грани ограничивающих коробок каждого узла, выровненные по осям локального координатного пространства этого узла, с добавленным уровнем прозрачности. |
| TransparentBoundingBoxOutline | `6` | Отображает ребра и грани ограничивающих коробок каждого узла, выровненные по осям локального координатного пространства этого узла, с добавленным уровнем прозрачности. |
| Wireframe | `7` | Отображает только ребра в одном цвете. |
| ShadedWireframe | `8` | Отображает только ребра, при этом интерполирует их цвет между двумя вершинами и применяет освещение. |
| HiddenWireframe | `9` | Отображает ребра в одном цвете, при этом удаляет обратные и скрытые ребра. |
| Vertices | `10` | Отображает только вершины в одном цвете. |
| ShadedVertices | `11` | Отображает только вершины, при этом использует их цвет вершины и применяет освещение. |
| Illustration | `12` | Отображает контурные ребра с поверхностями, удаляет скрытые линии. |
| SolidOutline | `13` | Отображает контурные ребра с освещёнными и текстурированными поверхностями, удаляет скрытые линии. |
| ShadedIllustration | `14` | Отображает контурные ребра с освещёнными и текстурированными поверхностями и дополнительным эмиссивным компонентом для удаления слабо освещённых областей произведения. |
