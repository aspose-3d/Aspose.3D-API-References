## Discreet3dsLoadOptions.GammaCorrectedColor property

Файл 3ds может содержать оригинальный цвет и цвет с гамма‑коррекцией для одного и того же атрибута; установка этого параметра в true заставит использовать цвет с гамма‑коррекцией, если это возможно, иначе Aspose.3D попытается использовать оригинальный цвет.

```csharp
public bool GammaCorrectedColor { get; set; }
```
