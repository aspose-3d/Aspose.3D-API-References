## FbxSaveOptions.EmbedTextures property

Получает или задает, следует ли встраивать текстуру в конечный выходной файл. Экспортер FBX попытается найти необработанные данные текстуры из [`FileSystem`](../../ioconfig/filesystem/), и встроить файл в конечный FBX файл. Значение по умолчанию — false.

```csharp
public bool EmbedTextures { get; set; }
```
