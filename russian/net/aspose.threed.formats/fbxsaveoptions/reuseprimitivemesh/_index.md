## FbxSaveOptions.ReusePrimitiveMesh property

Повторно использовать сетку для примитивов с одинаковыми параметрами, это значительно уменьшит размер вывода FBX, если сцена была построена большим набором примитивных форм (например, импортированных из файлов CAD). Значение по умолчанию — false.

public bool ReusePrimitiveMesh { get; set; }
