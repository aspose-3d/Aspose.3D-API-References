## PbrMaterial.Transparency property

Получает или задает коэффициент прозрачности. Коэффициент должен находиться в диапазоне от 0 (0 %, полностью непрозрачно) до 1 (100 %, полностью прозрачно). Любое недопустимое значение будет ограничено.

```csharp
public double Transparency { get; set; }
```

### Property Value

Коэффициент прозрачности.
