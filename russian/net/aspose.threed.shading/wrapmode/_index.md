## WrapMode enumeration

Режим обёртки текстуры.

```csharp
public enum WrapMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Wrap | `0` | Повторяет текстуру на поверхности модели, создавая повторяющийся узор. |
| Clamp | `1` | Прижимает текстуру к последнему пикселю на границе. |
| Mirror | `2` | Текстура будет повторяться, но будет зеркально отражаться, когда целая часть координаты нечётна. |
| MirrorOnce | `3` | Текстура будет один раз зеркально отражена, а затем прижата к максимальному значению. |
| Border | `4` | Координаты, выходящие за диапазон [0.0, 1.0], устанавливаются в указанный цвет границы. |
