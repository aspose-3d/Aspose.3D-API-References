Базовое пространство имён Aspose.3D

## Классы

| Класс | Описание |
| --- | --- |
| [A3DObject](./a3dobject/) | Базовый класс всех объектов Aspose.ThreeD, все подклассы будут поддерживать динамические свойства. |
| [AssetInfo](./assetinfo/) | Информация об активе. Информацию об активе можно прикрепить к [`Scene`](../aspose.threed/scene/). Дочерний [`Scene`](../aspose.threed/scene/) может иметь собственный [`AssetInfo`](../aspose.threed/assetinfo/) для переопределения определения родителя. |
| [AxisSystem](./axissystem/) | Система координат представляет собой комбинацию системы координат, вектора вверх и вектора вперёд. |
| [BonePose](./bonepose/) | [`BonePose`](../aspose.threed/bonepose/) содержит матрицу преобразования для кости. |
| [CustomObject](./customobject/) | Метаданные или пользовательские объекты, используемые в 3D‑файлах, управляются этим классом. Все пользовательские свойства сохраняются как динамические свойства. |
| [Entity](./entity/) | Базовый класс всех сущностей. Сущность представляет конкретный объект, прикреплённый к узлу, например [`Light`](../aspose.threed.entities/light/)/[`Geometry`](../aspose.threed.entities/geometry/). |
| [ExportException](./exportexception/) | Исключения, когда Aspose.3D не удалось экспортировать сцену в файл |
| [FileFormat](./fileformat/) | Определение формата файла |
| [FileFormatType](./fileformattype/) | Тип формата файла |
| [GlobalTransform](./globaltransform/) | Глобальное преобразование аналогично [`Transform`](../aspose.threed/transform/), но оно неизменно, поскольку представляет окончательное вычисленное преобразование. При вычислении глобального преобразования используется правосторонняя система координат |
| [Group](./group/) | [`Group`](../aspose.threed/group/) представляет логические отношения [`Node`](../aspose.threed/node/). |
| [ImageRenderOptions](./imagerenderoptions/) | Параметры для [`Render`](../aspose.threed/scene/render/) и [`Render`](../aspose.threed/scene/render/) |
| [ImportException](./importexception/) | Исключение, когда Aspose.3D не удалось открыть указанный источник |
| [License](./license/) | Предоставляет методы для лицензирования компонента. |
| [Metered](./metered/) | Предоставляет методы для установки измеряемого ключа. |
| [Node](./node/) | Представляет элемент в графе сцены. Граф сцены — это дерево объектов Node. Службы управления деревом находятся внутри этого класса. Обратите внимание, что SDK Aspose.3D не проверяет корректность построенного графа сцены. Ответственность за то, чтобы не создавать циклические графы в иерархии узлов, лежит на вызывающем коде. Помимо управления деревом, этот класс определяет все свойства, необходимые для описания позиции объекта в сцене. Эта информация включает базовые свойства Перемещения, Вращения и Масштабирования, а также более продвинутые параметры для точек опоры, ограничений и атрибутов IK‑соединений, таких как жёсткость и демпфирование. При первом создании объект Node является «пустым» (т.е. объектом без графического представления, содержащим только информацию о позиции). В этом состоянии его можно использовать для представления родителей в структуре дерева узлов, но не гораздо больше. Обычное применение таких объектов — добавить к ним сущность, которая специализирует узел (см. "Entity"). Сущность является самостоятельным объектом и соединена с Node. Это также означает, что одна и та же сущность может быть общей для нескольких узлов. Camera, Light, Mesh и т.д. — все являются сущностями и наследуются от базового класса Entity. |
| [NodeVisitor](./nodevisitor/) | Обратный вызов для обхода всей иерархии узлов. |
| [Pose](./pose/) | Позировка используется для хранения матрицы преобразования, когда геометрия скинована. Позировка представляет собой набор [`BonePose`](../aspose.threed/bonepose/), каждый [`BonePose`](../aspose.threed/bonepose/) сохраняет конкретную информацию о преобразовании узла кости. |
| [Property](./property/) | Класс для хранения пользовательских свойств. |
| [PropertyCollection](./propertycollection/) | Коллекция свойств |
| [Scene](./scene/) | Сцена — это объект верхнего уровня, содержащий узлы, геометрии, материалы, текстуры, анимацию, позы, подсцены и т.д. Сцена может иметь подсцены, обеспечивая поддержку нескольких документов в файлах, таких как collada/blender/fbx. Иерархию узлов можно получить через [`RootNode`](../aspose.threed/scene/rootnode/). [`Library`](../aspose.threed/scene/library/) используется для хранения ссылок на несвязанные объекты во время сериализации (например, метаданные или пользовательские объекты), чтобы их можно было использовать как библиотеку. |
| [SceneObject](./sceneobject/) | Корневой класс объектов, которые будут храниться внутри сцены. |
| [Transform](./transform/) | Трансформ содержит информацию, позволяющую получить доступ к перемещению/масштабированию/вращению объекта или к матрице преобразования с минимальными затратами. Это используется локальным трансформом. |
| [TrialException](./trialexception/) | Это исключение возникает в Scene.Open/Scene.Save, когда не применены лицензии. Вы можете отключить это исключение, установив SuppressTrialException в true. |
