## TrialException.SuppressTrialException property

Устанавливает значение true, чтобы подавить исключение пробной версии при использовании без лицензии, но ограничения не будут сняты. Чтобы снять ограничения, пожалуйста, используйте действующую лицензию. Установка значения true также означает, что вы осведомлены о ограничениях при использовании без лицензии.

```csharp
public static bool SuppressTrialException { get; set; }
```
