Все вспомогательные классы определены в этом пространстве имён.

## Классы

| Класс | Описание |
| --- | --- |
| [FileSystem](./filesystem/) | Инкапсуляция файловой системы. Aspose.3D будет использовать это для чтения/записи зависимостей. |
| [IOExtension](./ioextension/) | Утилиты для записи матрицы/вектора в бинарный писатель. |
| [MathUtils](./mathutils/) | Набор полезных математических утилит. |
| [ParseException](./parseexception/) | Исключение, когда Aspose.3D не удалось разобрать ввод. |
| [SemanticAttribute](./semanticattribute/) | Позволить пользователю использовать собственную структуру для статического объявления [`VertexDeclaration`](../aspose.threed.utilities/vertexdeclaration/) |
| [TransformBuilder](./transformbuilder/) | [`TransformBuilder`](../aspose.threed.utilities/transformbuilder/) используется для построения матрицы преобразования с помощью цепочки трансформаций. |
| [Vertex](./vertex/) | Ссылка на вершину, используемая для доступа к необработанной вершине в [`TriMesh`](../aspose.threed.entities/trimesh/). |
| [VertexDeclaration](./vertexdeclaration/) | Объявление структуры пользовательской вершины. |
| [VertexField](./vertexfield/) | Описание расположения полей вершины в памяти. |
| [Watermark](./watermark/) | Утилита для кодирования/декодирования скрытой водяной метки в/из сетки. |
