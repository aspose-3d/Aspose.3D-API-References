## AngleBetween(Vector3, Vector3) {#anglebetween_1}

Вычисляет внутренний угол между двумя направлениями. Два направления могут быть ненормализованными векторами

```csharp
public double AngleBetween(Vector3 dir, Vector3 up)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| dir | Vector3 | Вектор направления для сравнения |
| up | Vector3 | Вектор вверх общей плоскости двух направлений |

### Возвращаемое значение

внутренний угол в радианах
