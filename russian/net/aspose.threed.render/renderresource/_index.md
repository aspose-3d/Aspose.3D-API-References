## RenderResource class

Абстрактный класс всех ресурсов рендеринга. Все ресурсы рендеринга будут освобождены при освобождении рендерера. Классы, такие как [`Mesh`](../../aspose.threed.entities/mesh/)/[`Texture`](../../aspose.threed.shading/texture/), будут иметь соответствующий RenderResource.

public abstract class RenderResource : IDisposable
