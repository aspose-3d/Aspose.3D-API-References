## AnimationChannel.DefaultValue property

Получает или задает значение по умолчанию канала. Если у канала нет подключенных последовательностей ключевых кадров, значение по умолчанию будет использоваться при оценке анимации. Реальный пример: анимация изменяет только координату x узла, координаты y и z не меняются, тогда значение по умолчанию будет использовано при полной оценке трансляции.

```csharp
public object DefaultValue { get; set; }
```
