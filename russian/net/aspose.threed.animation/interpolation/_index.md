## Interpolation enumeration

Тип интерполяции ключевого кадра.

```csharp
public enum Interpolation
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Constant | `0` | Значение будет оставаться постоянным, равным значению первой точки, до следующего сегмента. |
| Linear | `1` | Линейная интерполяция — это прямая линия между двумя точками. |
| Bezier | `2` | Кривая Безье или сплайн Эрмита. |
| BSpline | `3` | Базисные сплайны определяются рядом контрольных точек, при этом кривая гарантированно проходит только через первую и последнюю точку. |
| CardinalSpline | `4` | Кардинальный сплайн — это кубический сплайн Эрмита, у которого касательные определяются конечными точками и параметром натяжения. |
| TCBSpline | `5` | Также называемый сплайном Коханека-Бартелса, поведение касательной определяется параметрами натяжения/смещения/непрерывности. |
