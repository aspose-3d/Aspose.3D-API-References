## WeightedMode enumeration


### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Весы out и next in не используются. Когда расчёт требует информации о касательной, будет использовано значение по умолчанию (0.3333). |
| OutWeight | `1` | Касательная Out (правый) взвешена. |
| NextInWeight | `2` | Касательная Next in (левый) взвешена. |
| Both | `3` | Касательные out и next in взвешены. |
