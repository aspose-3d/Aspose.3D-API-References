## KeyFrame.StepMode property

Получает или задает режим шага ключа. Если тип интерполяции — Constant, list.data[index] определяет, значение какого ключевого кадра будет использоваться при интерполяции. PreviousValue означает, что будет использовано значение левого ключевого кадра, а NextValue — значение следующего правого ключевого кадра.

```csharp
public StepMode StepMode { get; set; }
```

### Property Value

Режим шага.
