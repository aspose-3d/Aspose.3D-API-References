Все классы 2D профилей определены в этом пространстве имён.

## Классы

| Класс | Описание |
| --- | --- |
| [ArbitraryProfile](./arbitraryprofile/) | Этот класс позволяет напрямую создавать 2D‑профиль из произвольной кривой. |
| [CenterLineProfile](./centerlineprofile/) | Совместимый с IFC профиль центральной линии |
| [CircleShape](./circleshape/) | Совместимый с IFC круговой профиль, который можно использовать для построения сетки через [`LinearExtrusion`](../aspose.threed.entities/linearextrusion/) |
| [CShape](./cshape/) | Совместимый с IFC профиль C-образной формы, определяемый параметрами. Центральное положение профиля находится в центре ограничивающего бокса. |
| [EllipseShape](./ellipseshape/) | Совместимый с IFC профиль эллиптической формы, определяемый параметрами. Центральное положение профиля находится в центре ограничивающего бокса. |
| [FontFile](./fontfile/) | Файл шрифта содержит определения глифов, он используется для создания текстового профиля. |
| [HollowCircleShape](./hollowcircleshape/) | Совместимый с IFC полый круговой профиль. |
| [HollowRectangleShape](./hollowrectangleshape/) | Совместимый с IFC полый прямоугольный профиль с закруглёнными внутренними и внешними углами. |
| [HShape](./hshape/) | [`HShape`](../aspose.threed.profiles/hshape/) предоставляет определяющие параметры формы 'H' или 'I'. |
| [LShape](./lshape/) | Совместимый с IFC профиль L-образной формы, определяемый параметрами. |
| [MirroredProfile](./mirroredprofile/) | Совместимый с IFC зеркальный профиль. Этот профиль определяет новый профиль, отражая базовый профиль относительно оси y. |
| [ParameterizedProfile](./parameterizedprofile/) | Базовый класс всех параметризированных профилей. |
| [Profile](./profile/) | 2D профиль в плоскости xy |
| [RectangleShape](./rectangleshape/) | Прямоугольная форма, совместимая с IFC, со скруглёнными углами. |
| [Text](./text/) | Текстовый профиль, этот профиль описывает контуры с использованием шрифта и текста. |
| [TrapeziumShape](./trapeziumshape/) | Трапецеидальная форма, совместимая с IFC, определённая параметрами. |
| [TShape](./tshape/) | Т-образная форма, совместимая с IFC, определённая параметрами. |
| [UShape](./ushape/) | U-образная форма, совместимая с IFC, определённая параметрами. |
| [ZShape](./zshape/) | Z-образный профиль, совместимый с IFC, определённый параметрами. |
