## Frustum.RotationMode property

Получает или задает режим ориентации фрустума. Это свойство работает только когда [`Target`](../target/) равен null. Если значение FixedTarget, направление всегда вычисляется свойством [`LookAt`](../lookat/). В противном случае [`LookAt`](../lookat/) всегда вычисляется свойством [`Direction`](../direction/)

```csharp
public RotationMode RotationMode { get; set; }
```
