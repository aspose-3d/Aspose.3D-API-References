## MappingMode enumeration

Определяет, как элемент отображается на поверхность. `MappingMode` определяет, как [`VertexElement`](../vertexelement/) отображается на поверхность геометрии.

```csharp
public enum MappingMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ControlPoint | `0` | Каждый набор данных отображается на контрольную точку геометрии. |
| PolygonVertex | `1` | Данные отображаются на вершину полигона. Когда контрольная точка используется несколькими полигонами, и данные отображаются как PolygonVertex, контрольная точка как разные вершины полигона будет иметь свои собственные данные. |
| Polygon | `2` | Данные отображаются на полигон. Каждая вершина полигона использует одни и те же данные, когда режим отображения — Polygon. |
| Edge | `3` | Данные отображаются на ребро. Каждая конечная точка ребра использует одни и те же данные, когда режим отображения — Edge. |
| AllSame | `4` | Один набор данных отображается на всю поверхность. Как бы ни интерпретировались данные — как контрольные точки/вершины полигона/конечные точки ребер, они всегда одинаковы, как определено параметром AllSame. |
