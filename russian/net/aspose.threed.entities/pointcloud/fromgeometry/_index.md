## FromGeometry(Geometry, int) {#fromgeometry_1}

Создать новый экземпляр облака точек из геометрического объекта. Плотность — это количество точек на единичный треугольник (единичный треугольник — это треугольник с максимальной площадью из сетки).

```csharp
public static PointCloud FromGeometry(Geometry g, int density)
```

| Параметр | Тип | Описание |
