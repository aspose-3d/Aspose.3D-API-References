## ApertureMode enumeration

Режимы диафрагмы камеры. Режим диафрагмы определяет, какие значения управляют диафрагмой камеры. Если режим диафрагмы — HorizAndVert, Horizontal или Vertical, используется поле зрения. Если режим диафрагмы — FocalLength, используется фокусное расстояние.

```csharp
public enum ApertureMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| HorizAndVert | `0` | Установите значения углов для горизонтальных и вертикальных настроек. |
| Horizontal | `1` | Установите только горизонтальный угол. |
| Vertical | `2` | Установите только вертикальный угол. |
| FocalLength | `3` | Используйте фокусное расстояние напрямую. |
