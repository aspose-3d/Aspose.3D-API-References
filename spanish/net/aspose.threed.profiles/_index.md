Todas las clases de perfiles 2D se definen en este espacio de nombres.

## Clases

| Clase | Descripción |
| --- | --- |
| [ArbitraryProfile](./arbitraryprofile/) | Esta clase le permite construir un perfil 2D directamente a partir de una curva arbitraria. |
| [CenterLineProfile](./centerlineprofile/) | Perfil de línea central compatible con IFC |
| [CircleShape](./circleshape/) | Perfil circular compatible con IFC, que puede usarse para construir una malla mediante [`LinearExtrusion`](../aspose.threed.entities/linearextrusion/) |
| [CShape](./cshape/) | Perfil de forma C compatible con IFC definido por parámetros. La posición central del perfil está en el centro del cuadro delimitador. |
| [EllipseShape](./ellipseshape/) | Forma elíptica compatible con IFC definida por parámetros. La posición central del perfil está en el centro del cuadro delimitador. |
| [FontFile](./fontfile/) | El archivo de fuente contiene definiciones de glifos, y se usa para crear un perfil de texto. |
| [HollowCircleShape](./hollowcircleshape/) | Perfil de círculo hueco compatible con IFC. |
| [HollowRectangleShape](./hollowrectangleshape/) | Forma rectangular hueca compatible con IFC con esquinas redondeadas internas/externas. |
| [HShape](./hshape/) | El [`HShape`](../aspose.threed.profiles/hshape/) proporciona los parámetros definitorios de una forma 'H' o 'I'. |
| [LShape](./lshape/) | Perfil de forma L compatible con IFC definido por parámetros. |
| [MirroredProfile](./mirroredprofile/) | Perfil espejo compatible con IFC. Este perfil define un nuevo perfil al reflejar el perfil base respecto al eje y. |
| [ParameterizedProfile](./parameterizedprofile/) | La clase base de todos los perfiles parametrizados. |
| [Profile](./profile/) | Perfil 2D en el plano xy |
| [RectangleShape](./rectangleshape/) | Forma rectangular compatible con IFC con esquinas redondeadas. |
| [Text](./text/) | Perfil de texto, este perfil describe contornos usando fuentes y texto. |
| [TrapeziumShape](./trapeziumshape/) | Forma de trapecio compatible con IFC definida por parámetros. |
| [TShape](./tshape/) | Forma en T compatible con IFC definida por parámetros. |
| [UShape](./ushape/) | Forma en U compatible con IFC definida por parámetros. |
| [ZShape](./zshape/) | Perfil en forma Z compatible con IFC definido por parámetros. |
