## RenderResource class

La clase abstracta de todos los recursos de renderizado. Todos los recursos de renderizado se liberarán cuando se libere el renderizador. Clases como [`Mesh`](../../aspose.threed.entities/mesh/)/[`Texture`](../../aspose.threed.shading/texture/) tendrán un RenderResource correspondiente.

```csharp
public abstract class RenderResource : IDisposable
```
