## GltfSaveOptions.MaterialConverter property

Convertidor personalizado para convertir el material de la geometría a material PBR. Si no está asignado, el exportador glTF 2.0 convertirá automáticamente el material estándar a material PBR. El valor predeterminado es null. Esta propiedad se usa al exportar una escena a un archivo glTF 2.0.

```csharp
public MaterialConverter MaterialConverter { get; set; }
```
