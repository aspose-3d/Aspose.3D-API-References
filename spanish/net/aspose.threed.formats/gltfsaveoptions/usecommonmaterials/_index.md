## GltfSaveOptions.UseCommonMaterials property

Serializa materiales usando extensiones de material comunes KHR, el valor predeterminado es false. Establecer esto en false hará que Aspose.3D exporte un conjunto de shaders de vértice/fragmento si ExportShaders

```csharp
public bool UseCommonMaterials { get; set; }
```

## Observaciones

Esta propiedad solo funciona para glTF 1.0
