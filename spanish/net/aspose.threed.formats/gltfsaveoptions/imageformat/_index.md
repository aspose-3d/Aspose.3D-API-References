## GltfSaveOptions.ImageFormat property

El glTF estándar solo admite PNG/JPG como su formato de textura, esta opción guiará cómo Aspose.3D convierte las imágenes no estándar al formato compatible durante la exportación. El valor predeterminado es Png.

public GltfEmbeddedImageFormat ImageFormat { get; set; }
