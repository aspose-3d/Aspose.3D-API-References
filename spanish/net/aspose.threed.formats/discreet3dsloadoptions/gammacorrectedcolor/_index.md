## Discreet3dsLoadOptions.GammaCorrectedColor property

Un archivo 3ds puede contener el color original y el color corregido por gamma para el mismo atributo; al establecer esto en true se usará el color corregido por gamma si es posible, de lo contrario Aspose.3D intentará usar el color original.

```csharp
public bool GammaCorrectedColor { get; set; }
```
