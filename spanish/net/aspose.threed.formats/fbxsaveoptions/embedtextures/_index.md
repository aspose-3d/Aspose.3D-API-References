## FbxSaveOptions.EmbedTextures property

Obtiene o establece si se incrusta la textura en el archivo de salida final. FBX Exporter intentará encontrar los datos sin procesar de la textura desde [`FileSystem`](../../ioconfig/filesystem/), e incrustará el archivo en el FBX final. El valor predeterminado es false.

```csharp
public bool EmbedTextures { get; set; }
```
