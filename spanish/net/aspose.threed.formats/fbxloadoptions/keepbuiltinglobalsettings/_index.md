## FbxLoadOptions.KeepBuiltinGlobalSettings property

Obtiene o establece si se deben conservar las propiedades integradas en GlobalSettings que tienen un reemplazo de propiedad nativa en [`AssetInfo`](../../../aspose.threed/assetinfo/). Establezca esto en true si desea las propiedades completas en GlobalSettings. El valor predeterminado es false

public bool KeepBuiltinGlobalSettings { get; set; }
