## Discreet3dsSaveOptions.HighPreciseColor property

Si esto es true, el archivo 3ds generado usará color de alta precisión, lo que significa que cada canal de rojo/verde/azul está en punto flotante de 32 bits. De lo contrario, el archivo generado usará color de 24 bits, cada canal usa un byte de 8 bits. El valor predeterminado es false, porque no todas las aplicaciones admiten el color de alta precisión.

```csharp
public bool HighPreciseColor { get; set; }
```
