## Bone.Node property

Obtiene o establece el nodo. El nodo de hueso es el hueso al que se adjunta la piel, el [`SkinDeformer`](../../skindeformer/) usará el nodo de hueso para influir en el desplazamiento de los puntos de control. El nodo de hueso suele tener un [`Skeleton`](../../../aspose.threed.entities/skeleton/) adjunto, pero no es obligatorio. El [`Skeleton`](../../../aspose.threed.entities/skeleton/) adjunto suele ser usado por el software DCC para mostrar el esqueleto al usuario.

```csharp
public Node Node { get; set; }
```
