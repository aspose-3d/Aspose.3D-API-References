## NurbsCurve.Rational property

Obtiene o establece si es racional, este valor indica si este [`NurbsCurve`](../) es una spline racional o una spline no racional. La B-spline no racional es un caso especial de B-splines racionales.

```csharp
public bool Rational { get; set; }
```

### Property Value

true si es una spline racional; de lo contrario, false es una spline no racional.
