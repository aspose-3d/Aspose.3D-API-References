## Frustum.RotationMode property

Obtiene o establece el modo de orientación del frustum. Esta propiedad solo funciona cuando el [`Target`](../target/) es nulo. Si el valor es FixedTarget, la dirección siempre se calcula mediante la propiedad [`LookAt`](../lookat/). De lo contrario, el [`LookAt`](../lookat/) siempre se calcula mediante el [`Direction`](../direction/)

```csharp
public RotationMode RotationMode { get; set; }
```
