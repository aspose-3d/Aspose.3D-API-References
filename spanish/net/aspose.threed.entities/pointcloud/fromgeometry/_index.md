## FromGeometry(Geometry, int) {#fromgeometry_1}

Crear una nueva instancia de nube de puntos a partir de un objeto de geometría. La densidad es el número de puntos por triángulo unitario (Los triángulos unitarios son los triángulos con el área de superficie máxima de la malla)

```csharp
public static PointCloud FromGeometry(Geometry g, int density)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| g | Geometría | Instancia de malla u otra geometría |
| densidad | Int32 | Número de puntos por triángulo unitario |
