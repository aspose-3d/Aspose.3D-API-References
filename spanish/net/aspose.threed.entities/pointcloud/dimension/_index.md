## PointCloud.Dimension property

Si se proporciona un valor de dimensión para la nube de puntos, indica una nube de puntos organizada. Sin un tamaño especificado, se considera una nube de puntos desorganizada. Una nube de puntos organizada significa que tiene una estructura similar a una imagen.
