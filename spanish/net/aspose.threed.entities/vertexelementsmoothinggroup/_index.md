## VertexElementSmoothingGroup class

Un grupo de suavizado es un conjunto de polígonos en una malla de polígonos que debe aparecer como una superficie lisa. Algunos softwares de modelado 3D tempranos como 3D Studio Max para DOS usaban grupos de suavizado para evitar almacenar el vector normal de cada vértice de la malla.
