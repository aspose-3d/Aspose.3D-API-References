## AnimationChannel.DefaultValue property

Obtiene o establece el valor predeterminado del canal. Si un canal no tiene secuencias de fotogramas clave conectadas, se utilizará el valor predeterminado durante la evaluación de la animación. Un caso real: la animación solo anima la coordenada x de un nodo, las coordenadas y y z no se modifican, entonces se usará el valor predeterminado durante la evaluación completa de la traducción.

```csharp
public object DefaultValue { get; set; }
```
