## GetKeyframeSequence(A3DObject, string, string, bool) {#getkeyframesequence_1}

Obtiene la secuencia de fotogramas clave en la propiedad y canal dados.

```csharp
public KeyframeSequence GetKeyframeSequence(A3DObject target, string propName, string channelName, 
    bool create)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |

| propName | String | El nombre de la propiedad. |
| channelName | String | El nombre del canal. |
