## WeightedMode enumeration

Modo ponderado.

```csharp

public enum WeightedMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | Tanto los pesos out como los next in no se utilizan. Cuando el cálculo necesita información de la tangente, se usará el valor predeterminado (0.3333). |
| OutWeight | `1` | La tangente Out(right) está ponderada. |
| NextInWeight | `2` | La tangente Next in(left) está ponderada. |
| Both | `3` | Ambas tangentes out y next in están ponderadas. |
