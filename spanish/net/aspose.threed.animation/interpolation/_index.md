## Interpolation enumeration

El tipo de interpolación del fotograma clave.

```csharp
public enum Interpolation
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Constant | `0` | El valor permanecerá constante al valor del primer punto hasta el siguiente segmento. |
| Linear | `1` | La interpolación lineal es una línea recta entre dos puntos. |
| Bezier | `2` | Una spline Bézier o Hermite. |
| BSpline | `3` | Las splines de base se definen mediante una serie de puntos de control, para los cuales se garantiza que la curva solo pasa por el primer y el último punto. |
| CardinalSpline | `4` | Una spline cardinal es una spline cúbica Hermite cuyas tangentes se definen por los puntos finales y un parámetro de tensión. |
| TCBSpline | `5` | También llamada spline Kochanek-Bartels, el comportamiento de la tangente se define por tensión/sesgo/continuidad |
