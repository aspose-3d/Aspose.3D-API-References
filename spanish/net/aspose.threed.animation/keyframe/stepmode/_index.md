## KeyFrame.StepMode property

Obtiene o establece el modo de paso de la clave. Si el tipo de interpolación es Constante, list.data[index] decide qué valor de fotograma clave se usará durante la interpolación. Un PreviousValue significa que se usará el valor del fotograma clave izquierdo. Un NextValue significa que se usará el valor del siguiente fotograma clave derecho.

```csharp
public StepMode StepMode { get; set; }
```

### Property Value

El modo de paso.
