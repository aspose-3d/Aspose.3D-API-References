## TrialException.SuppressTrialException property

Establece esto a true para suprimir la excepción de prueba en uso sin licencia, pero las restricciones no se levantarán. Para levantar las restricciones, por favor utiliza una licencia adecuada. Y establecer esto a true también significa que eres consciente de las restricciones sin licencia.

```csharp
public static bool SuppressTrialException { get; set; }
```
