## Transform.SetGeometricScaling method

Establece el escalado geométrico. La transformación geométrica solo afecta a las entidades adjuntas y deja los nodos hijos sin cambios. Se fusionará como transformación local cuando exportes la transformación geométrica a tipos de archivo que no lo soportan.

```csharp
public Transform SetGeometricScaling(double sx, double sy, double sz)
```

## Ejemplos

```csharp
Node node = new Node();
node.Transform.SetGeometricScaling(2, 2, 2);
```
