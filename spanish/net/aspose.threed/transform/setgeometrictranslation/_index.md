## Transform.SetGeometricTranslation method

Establece la traslación geométrica. La transformación geométrica solo afecta a las entidades adjuntas y deja los nodos hijos sin cambios. Se fusionará como transformación local cuando exportes la transformación geométrica a tipos de archivo que no lo soportan.

```csharp
public Transform SetGeometricTranslation(double x, double y, double z)
```

## Ejemplos

```csharp
Node node = new Node();
node.Transform.SetGeometricTranslation(10, 0, 0);
```
