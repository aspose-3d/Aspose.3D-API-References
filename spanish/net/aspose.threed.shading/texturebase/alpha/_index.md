## TextureBase.Alpha property

Obtiene o establece el valor alfa predeterminado de la textura. Esto es válido cuando el [`AlphaSource`](../alphasource/) es PixelAlpha. El valor predeterminado es 1.0, el rango válido está entre 0 y 1.

```csharp
public double Alpha { get; set; }
```
