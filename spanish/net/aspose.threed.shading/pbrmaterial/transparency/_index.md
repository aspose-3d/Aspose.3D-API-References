## PbrMaterial.Transparency property

Obtiene o establece el factor de transparencia. El factor debe estar en el rango entre 0 (0%, totalmente opaco) y 1 (100%, totalmente transparente). Cualquier valor de factor no válido será limitado.

```csharp
public double Transparency { get; set; }
```

### Property Value

El factor de transparencia.
