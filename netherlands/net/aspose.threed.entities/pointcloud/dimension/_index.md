## PointCloud.Dimension property

Als een dimensiewaarde aanwezig is voor de point cloud, duidt dit op een georganiseerde point cloud. Zonder een gespecificeerde grootte wordt het beschouwd als een ongeorganiseerde point cloud. Een georganiseerde point cloud betekent dat het een afbeelding-achtige structuur heeft.

public Vector2? Dimension { get; set; }
