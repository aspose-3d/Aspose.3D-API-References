## FbxLoadOptions.CompatibleMode property

互換モードを有効にするかどうかを取得または設定します。互換モードは、Blender でエクスポートされた PBR マテリアルなどの非標準 FBX 定義をサポートしようとします。デフォルト値は false です。

```csharp
public bool CompatibleMode { get; set; }
```
