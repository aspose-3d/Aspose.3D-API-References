## BoneLinkMode enumeration

ボーンのリンクモードは、階層構造内でボーンが親ボーンに接続またはリンクされる方法を指します。

```csharp
public enum BoneLinkMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Normalize | `0` | このモードでは、子ボーンの変換は親ボーンの変換に対して正規化されます。 |
| Additive | `1` | 加算モードは、子ボーンのローカル変換を親ボーンの変換に加えることで、子ボーンの変換を計算します。 |
| TotalOne | `2` | Total One は、親ボーンと子ボーンの合成変換が全体で1単位の長さにスケールするようにします。 |
