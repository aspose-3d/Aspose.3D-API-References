## PointCloud.Dimension property

ポイントクラウドに次元値が存在する場合、組織化されたポイントクラウドであることを示します。サイズが指定されていない場合は、非組織化ポイントクラウドとみなされます。組織化ポイントクラウドは、画像のような構造を持つことを意味します。

public Vector2? Dimension { get; set; }
