Toutes les classes de profils 2D sont définies dans cet espace de noms.

## Classes

| Classe | Description |
| --- | --- |
| [ArbitraryProfile](./arbitraryprofile/) | Cette classe vous permet de créer un profil 2D directement à partir d'une courbe arbitraire. |
| [CenterLineProfile](./centerlineprofile/) | Profil de ligne centrale compatible IFC |
| [CircleShape](./circleshape/) | Profil circulaire compatible IFC, qui peut être utilisé pour construire un maillage via [`LinearExtrusion`](../aspose.threed.entities/linearextrusion/) |
| [CShape](./cshape/) | Profil en forme de C compatible IFC défini par des paramètres. La position centrale du profil se trouve au centre de la boîte englobante. |
| [EllipseShape](./ellipseshape/) | Forme d'ellipse compatible IFC définie par des paramètres. La position centrale du profil se trouve au centre de la boîte englobante. |
| [FontFile](./fontfile/) | Le fichier de police contient les définitions des glyphes, il est utilisé pour créer un profil de texte. |
| [HollowCircleShape](./hollowcircleshape/) | Profil de cercle creux compatible IFC. |
| [HollowRectangleShape](./hollowrectangleshape/) | Forme rectangulaire creuse compatible IFC avec coins arrondis intérieurs et extérieurs. |
| [HShape](./hshape/) | Le [`HShape`](../aspose.threed.profiles/hshape/) fournit les paramètres définissant une forme en 'H' ou en 'I'. |
| [LShape](./lshape/) | Profil en forme de L compatible IFC défini par des paramètres. |
| [MirroredProfile](./mirroredprofile/) | Profil miroir compatible IFC. Ce profil définit un nouveau profil en reflétant le profil de base autour de l'axe y. |
| [ParameterizedProfile](./parameterizedprofile/) | La classe de base de tous les profils paramétrés. |
| [Profile](./profile/) | Profil 2D dans le plan xy |
| [RectangleShape](./rectangleshape/) | Forme rectangulaire compatible IFC avec des coins arrondis. |
| [Text](./text/) | Profil texte, ce profil décrit les contours en utilisant la police et le texte. |
| [TrapeziumShape](./trapeziumshape/) | Forme trapézoïdale compatible IFC définie par des paramètres. |
| [TShape](./tshape/) | Forme en T compatible IFC définie par des paramètres. |
| [UShape](./ushape/) | Forme en U compatible IFC définie par des paramètres. |
| [ZShape](./zshape/) | Profil en forme de Z compatible IFC défini par des paramètres. |
