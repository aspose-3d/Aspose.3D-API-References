## TrialException.SuppressTrialException property

Définissez cette valeur sur true pour supprimer l'exception d'essai en cas d'utilisation non licenciée, mais les restrictions ne seront pas levées. Pour lever les restrictions, veuillez utiliser une licence appropriée. Définir cette valeur sur true signifie également que vous êtes conscient des restrictions liées à l'absence de licence.

```csharp
public static bool SuppressTrialException { get; set; }
```
