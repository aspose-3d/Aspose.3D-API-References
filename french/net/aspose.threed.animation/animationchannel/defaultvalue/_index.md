## AnimationChannel.DefaultValue property

Obtient ou définit la valeur par défaut du canal. Si un canal n'a aucune séquence d'images clés connectée, la valeur par défaut sera utilisée pendant l'évaluation de l'animation. Un scénario réel : l'animation ne modifie que la coordonnée x d'un nœud, les y et z ne sont pas changés, alors la valeur par défaut sera utilisée pendant l'évaluation complète de la translation.

```csharp
public object DefaultValue { get; set; }
```
