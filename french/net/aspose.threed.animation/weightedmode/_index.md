## WeightedMode enumeration

Mode pondéré.

```csharp
[Flags]
public enum WeightedMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Les poids out et next in ne sont pas utilisés. Lorsque le calcul nécessite des informations de tangente, la valeur par défaut (0,3333) sera utilisée. |
| OutWeight | `1` | La tangente Out (droite) est pondérée. |
| NextInWeight | `2` | La tangente Next in (gauche) est pondérée. |
| Both | `3` | Les tangentes out et next in sont toutes deux pondérées. |
