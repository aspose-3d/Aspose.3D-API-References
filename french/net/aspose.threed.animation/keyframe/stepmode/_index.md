## KeyFrame.StepMode property

Obtient ou définit le mode d'étape de l'image clé. Si le type d'interpolation est Constant, list.data[index] détermine quelle valeur d'image clé sera utilisée pendant l'interpolation. Une PreviousValue signifie que la valeur de l'image clé de gauche sera utilisée. Une NextValue signifie que la valeur de l'image clé de droite suivante sera utilisée.

```csharp
public StepMode StepMode { get; set; }
```

### Property Value

Le mode d'étape.
