## PbrMaterial.Transparency property

Obtient ou définit le facteur de transparence. Le facteur doit être compris entre 0 (0 %, totalement opaque) et 1 (100 %, totalement transparent). Toute valeur de facteur invalide sera tronquée.

```csharp
public double Transparency { get; set; }
```

### Property Value

Le facteur de transparence.
