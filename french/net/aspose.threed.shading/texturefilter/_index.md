## TextureFilter enumeration

Options de filtrage lors de l’échantillonnage de la texture.

```csharp
public enum TextureFilter
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Pas de minification, ceci n'est utilisé que par le filtre de minification. |
| Point | `1` | Utiliser l'échantillonnage point |
| Linear | `2` | Utiliser l'interpolation linéaire pour l'échantillonnage |
| Anisotropic | `3` | Utiliser l'interpolation anisotrope pour l'échantillonnage, ceci n'est utilisé que par le filtre de minification. |
