## GltfSaveOptions.ImageFormat property

Le glTF standard ne prend en charge que les formats PNG/JPG comme textures, cette option indique comment Aspose.3D convertit les images non standard vers un format pris en charge lors de l'exportation. La valeur par défaut est Png.

public GltfEmbeddedImageFormat ImageFormat { get; set; }
