## GltfSaveOptions.UseCommonMaterials property

Sérialisez les matériaux en utilisant les extensions de matériau communes KHR, la valeur par défaut est false. Mettre cela à false entraînera l'exportation par Aspose.3D d'un ensemble de shaders vertex/fragment si ExportShaders.

```csharp
public bool UseCommonMaterials { get; set; }
```

## Remarques

Cette propriété ne fonctionne que pour glTF 1.0
