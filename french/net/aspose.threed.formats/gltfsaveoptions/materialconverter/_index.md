## GltfSaveOptions.MaterialConverter property

Convertisseur personnalisé pour transformer le matériau de la géométrie en matériau PBR. Si celui-ci n'est pas attribué, l'exportateur glTF 2.0 convertira automatiquement le matériau standard en matériau PBR. La valeur par défaut est null. Cette propriété est utilisée lors de l'exportation d'une scène vers un fichier glTF 2.0.

```csharp
public MaterialConverter MaterialConverter { get; set; }
```
