## Discreet3dsSaveOptions.GammaCorrectedColor property

Un fichier 3ds peut contenir la couleur originale et la couleur corrigée gamma pour le même attribut. Le définir sur true utilisera la couleur corrigée gamma si possible, sinon Aspose.3D essaiera d'utiliser la couleur originale.

```csharp
public bool GammaCorrectedColor { get; set; }
```
