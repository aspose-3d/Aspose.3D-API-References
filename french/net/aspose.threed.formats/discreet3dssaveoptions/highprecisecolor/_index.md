## Discreet3dsSaveOptions.HighPreciseColor property

Si cette valeur est true, le fichier 3ds généré utilisera une couleur haute précision, ce qui signifie que chaque canal rouge/vert/bleu est en flottant 32 bits. Sinon, le fichier généré utilisera une couleur 24 bits, chaque canal étant un octet de 8 bits. La valeur par défaut est false, car toutes les applications ne prennent pas en charge la couleur haute précision.

```csharp
public bool HighPreciseColor { get; set; }
```
