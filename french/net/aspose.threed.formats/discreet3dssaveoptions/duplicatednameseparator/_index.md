## Discreet3dsSaveOptions.DuplicatedNameSeparator property

Le séparateur entre le nom de l'objet et le compteur dupliqué, la valeur par défaut est "_". Lorsque la scène contient des objets qui utilisent le même nom, l'exportateur 3DS d'Aspose.3D générera un nom différent pour l'objet. Par exemple, il y a deux nœuds nommés "Box", le premier nœud aura le nom "Box", et le deuxième nœud recevra un nouveau nom "Box_2" en utilisant la configuration par défaut.

```csharp
public string DuplicatedNameSeparator { get; set; }
```
