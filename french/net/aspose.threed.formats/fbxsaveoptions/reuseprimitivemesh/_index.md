## FbxSaveOptions.ReusePrimitiveMesh property

Réutilisez le maillage pour les primitives avec les mêmes paramètres, cela réduira considérablement la taille de la sortie FBX dont la scène a été construite à partir d'un grand ensemble de formes primitives (comme importées depuis des fichiers CAD). La valeur par défaut est false.

```csharp
public bool ReusePrimitiveMesh { get; set; }
```
