## FbxLoadOptions.KeepBuiltinGlobalSettings property

Obtient ou définit si les propriétés intégrées dans GlobalSettings qui ont un remplacement de propriété natif dans [`AssetInfo`](../../../aspose.threed/assetinfo/). Définissez ceci sur true si vous voulez les propriétés complètes dans GlobalSettings. La valeur par défaut est false

public bool KeepBuiltinGlobalSettings { get; set; }
