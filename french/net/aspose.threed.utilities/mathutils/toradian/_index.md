## ToRadian(Vector3) {#toradian}

Convertir un [`Vector3`](../../vector3/) de degré en radian

```csharp
public static Vector3 ToRadian(Vector3 degree)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| degré | Vector3 | La valeur en degré. |

### Valeur de retour
