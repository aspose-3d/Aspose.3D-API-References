## Bone.Node property

Obtient ou définit le nœud. Le nœud d'os est l'os auquel la peau est attachée, le [`SkinDeformer`](../../skindeformer/) utilisera le nœud d'os pour influencer le déplacement des points de contrôle. Le nœud d'os possède généralement un [`Skeleton`](../../../aspose.threed.entities/skeleton/) attaché, mais ce n'est pas obligatoire. Le [`Skeleton`](../../../aspose.threed.entities/skeleton/) attaché est généralement utilisé par les logiciels DCC pour afficher le squelette à l'utilisateur.

```csharp
public Node Node { get; set; }
```
