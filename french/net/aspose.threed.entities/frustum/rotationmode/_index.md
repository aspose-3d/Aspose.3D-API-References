## Frustum.RotationMode property

Obtient ou définit le mode d'orientation du frustum. Cette propriété ne fonctionne que lorsque le [`Target`](../target/) est nul. Si la valeur est FixedTarget, la direction est toujours calculée par la propriété [`LookAt`](../lookat/). Sinon, le [`LookAt`](../lookat/) est toujours calculé par le [`Direction`](../direction/).

```csharp
public RotationMode RotationMode { get; set; }
```
