## ApertureMode enumeration

Modes d'ouverture de la caméra. Le mode d'ouverture détermine quelles valeurs contrôlent l'ouverture de la caméra. Si le mode d'ouverture est HorizAndVert, Horizontal ou Vertical, alors le champ de vision est utilisé. Si le mode d'ouverture est FocalLength, alors la distance focale est utilisée.

```csharp
public enum ApertureMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| HorizAndVert | `0` | Définissez les valeurs d'angle pour les réglages horizontaux et verticaux. |
| Horizontal | `1` | Définissez uniquement l'angle horizontal. |
| Vertical | `2` | Définissez uniquement l'angle vertical. |
| FocalLength | `3` | Utilisez la longueur focale directement. |
