## NurbsCurve.Rational property

Obtient ou définit si elle est rationnelle, cette valeur indique si ce [`NurbsCurve`](../) est un spline rationnel ou non rationnel. Un B-spline non rationnel est un cas particulier d'un B-spline rationnel.

```csharp
public bool Rational { get; set; }
```

### Property Value

true si c'est un spline rationnel ; sinon, false indique un spline non rationnel.
