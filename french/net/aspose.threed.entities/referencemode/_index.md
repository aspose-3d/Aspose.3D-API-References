## ReferenceMode enumeration

`ReferenceMode` définit comment les informations de mappage sont stockées et référencées par.

```csharp
public enum ReferenceMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Direct | `0` | Les données sont directement référencées |
| Index | `1` | Les données sont référencées par indice |
| IndexToDirect | `2` | Les données sont référencées par indice, puis accédées par indice dans la liste de données de [`VertexElement`](../vertexelement/). |
